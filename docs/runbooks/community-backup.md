# 다음카페·밴드 로컬 백업

기존 커뮤니티의 수집·증분·보존·백업 완료 기준이다. 2026-11-14 문서 정리로 이관 기준에서 분리했으며 기존 정책을 변경하지 않는다. 플랫폼별 상태는 [제품 계획](../product/planning-proposal.md#7-다음-개발-목표), 홈페이지 반영은 별도 [이관 기준](../product/community-archive-migration-proposal.md)을 따른다.

## 대상과 저장

- 다음카페 `dkkmob`: 운영 종료 시점까지의 전체 자료를 관리자 열람 범위에서 로컬에 보존한다.
- 밴드 `@dkom`: 운영 중인 자료를 한국 시간의 전날까지 수집하고 날짜별 증분·누락을 관리한다.
- 두 플랫폼의 백업과 마이그레이션은 네 개의 독립 작업이다. 백업 완료로 이관을 시작하지 않는다.
- 원본 폴더는 `local-backups/community/daum-dkkmob/`와 `local-backups/community/band-11089836/`로 구분한다. 목록·커서·날짜별 체크포인트도 플랫폼별로 관리한다.
- 공통 로컬 SQLite `local-backups/community/archive.sqlite3`는 `source`·`container_id`와 원본 복합 ID로 원천을 구분한다. 원문 JSON·다운로드 파일·기존 이력은 보존하며 캐시나 폐기 가능한 앱 테스트 데이터로 취급하지 않는다.
- 디렉터리 0700·파일 0600으로 제한하고 Git·Replit·클라우드 동기화에서 제외한다. 비밀번호·쿠키·인증 토큰은 저장하지 않는다.

## 날짜별 증분 수집

운영 중인 밴드에 적용한다. 기준 시간대는 `Asia/Seoul`이며, 실행 시작 시점의 당일 00:00을 배타적 상한으로 고정한다. 오늘 작성된 게시글·댓글·첨부는 대상 총건수에서도 제외하고 저장하거나 다운로드하지 않는다. 수정 시각이 제공되면 같은 상한을 적용한다. 2026-11-14 작업의 기준일은 2026-11-13이며 자동 실행 예약은 포함하지 않는다. 운영 종료한 다음카페는 종료 시점까지의 전체 자료를 대상으로 한다.

- 최초 백업에서 빠진 과거 자료는 기존 목록·커서로 이어서 보충한다. 이미 저장한 원본 ID·해시·파일은 재사용하며 매번 전체를 새로 수집하지 않는다.
- 이후 목록 탐색은 마지막으로 완료한 날짜 다음 날부터 전날까지다. 날짜별 목록 탐색 완료와 본문·댓글·첨부 확보 상태를 구분하고 실패·보류 항목은 별도 재처리 대상으로 남긴다.
- 원문을 저장하기 전에 항목별 원본 날짜를 검사한다. 과거 글의 댓글에도 별도로 적용한다. 오늘 자료가 섞인 목록 응답을 통째로 파일에 남기지 않는다. 날짜가 확인되지 않는 새 항목은 날짜 확인 대기로 기록하며 본문·첨부 수집은 보류한다.
- 이미 존재하는 백업은 이 정책 변경을 이유로 삭제하지 않는다. 수집 기준일·시간대·날짜별 건수·보류·실패와 체크포인트를 로컬에 기록한다.
- 밴드의 현재 관찰된 게시글·댓글 응답은 `created_at`을 제공하고 별도 수정 시각을 제공하지 않는다. 따라서 작성일 증분만으로 과거 글의 모든 수정·삭제 또는 실제 수정 날짜를 검출했다고 보고하지 않는다. 수집 중 관찰한 변경은 원본 버전으로 구분하며 원문을 자동 삭제하지 않는다.

과거 변경 확인이 필요하면 전체 목록을 재대조하고 동일 ID/해시의 본문·파일은 재저장하지 않는다. 삭제 여부가 확정되지 않은 자료는 기존 백업을 유지한다.

## 다음카페 백업 완료 기준

2026-11-14 사용자 결정으로 **현재 확보된 자료 기준 완료**로 마감한다. 하위 게시판 13개 전체 170건을 보존한다. 원 분류별로 `게시판` 83건·`동창회 소개` 35건·별도 동창회 앨범 52건이며 Q&A·댓글·한 줄 수다는 0건이다. 과거 수집 화면 형식별 집계인 ‘일반 글 87건·앨범형 자료 83건’을 원 카페 분류로 사용하지 않는다.

- 미확보 이미지 6개는 게시판·글 ID·본문 위치·원문 링크·수집 실패 사유를 기록한다. 같은 날 사용자가 원문에서 6개 모두 실제 그림이 남아 있지 않음을 직접 확인했다. 수집기의 실패 기록과 사용자 확인을 구분하며 누락을 확보 성공으로 바꾸지 않는다. 이 6개를 추가 확인·자동 재시도 대기로 남기지 않는다.
- 저장 이미지 438개에는 기존 원문의 ‘X Image’ 대체 그림 12개가 포함된다. 실제 그림이 보존된 426개와 구분하고 대체 그림도 원본 기록으로 유지한다. 이 수치는 본문 등장 횟수이며 고유 파일 수와 다르다.
- 상세 마감 기록과 6개 누락 목록은 Git 제외된 `local-backups/community/daum-dkkmob/backup-completion-2026-11-14.md`에 둔다. 확보한 원본·첨부·색인·과거 검사 결과를 보존하고 미확보 원문을 추정하거나 대체 생성하지 않는다.
- 완료 범위는 다음카페 로컬 백업뿐이다. 밴드 백업의 진행 상태와 두 플랫폼의 마이그레이션 상태는 별도로 유지한다.

수집·파일 검증과 당시 이관 전 상태는 [백업 기록](../history/community-backup-2026-11-14.md)에 보존한다. 원문과 상세 대응표는 Git 제외된 로컬 백업 트리에만 보관한다.
