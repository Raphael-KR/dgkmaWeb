# ADR 0004: 작성자 관리와 관리자 가리기 분리

- 상태: Accepted — 기존 사용자 확정 결정의 사후 기록
- 기록일: 2026-11-09. 제품 기준서에 기록된 같은 날짜의 관리 정책을 근거로 한다.
- 정본: [게시글 수정·삭제·가리기](../product/planning-proposal.md#게시글-수정삭제가리기-2026-11-09)

## 배경

게시 후 작성자의 정정·삭제와 관리자의 게시판 관리가 필요했다. 처음 요청된 관리자의 전체 글 수정·삭제 범위는 사용자의 후속 결정으로 가리기만 허용하는 방식으로 변경됐다.

## 결정과 비교한 선택지

`authorId`의 작성자만 본인 글을 수정·삭제한다. 관리자는 타인의 글을 가리거나 다시 표시하며, 관리자라는 이유로 본문을 수정·삭제하지 않는다. 관리자가 쓴 본인 글에는 작성자 권한을 적용한다. 경조사 대상 동문과 실제 등록자를 혼동하지 않는다.

일반 글은 기존 편집기를 사용한다. 경조사는 짧은 정정 → 사실 해석 → 문안 미리보기 → 작성자 확인을 유지하며 사실 JSON과 본문을 별개로 수정하지 않는다. 타인의 글을 관리자 권한으로 덮어쓰는 초기 선택지는 채택하지 않는다.

## 결과와 제약

서버 권한 판정과 가림 상태를 목록·상세·검색에 일관되게 적용한다. 수정 시 revision과 서명 미리보기 계약을 유지하며, 새 공개 URL 정정은 기존 링크보다 우선한다. 이 결정은 별도 신고·심사·알림 기능을 추가하지 않는다.
