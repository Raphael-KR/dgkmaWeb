# ADR 0005: 공개 규정 기반 권리회원 판정

- 상태: **Accepted — 목표 정책 확정, 구현·DB 적용 별도**
- 결정일: 2026-11-10
- 사용자 선택: “공개 규정 기준으로 정리”
- 현재 정책 정본: [제품·개발 계획](../product/planning-proposal.md#회원-등급과-회비)
- 규정 근거: [공개 회원관리 및 회계 규정 원문](../../client/src/features/about/regulations.tsx)의 제8~12조·부칙·별표 1. 이 결정은 규정 원문을 개정하지 않는다.

## 충돌과 선택

공개 규정과 현재 앱이 권리회원의 회비 기준을 다르게 설명했다. 공개 규정은 직책별 월회비 누계 또는 연납 기준이고, 현재 서버는 모든 회원에게 당해년도 완료된 연회비 합계 50,000원을 적용한다.

| 대안 | 결과 | 결정 |
|---|---|---|
| 공개 규정을 앱 목표 정책으로 채택 | 월납·직책·명예회원·과거 상태 보존을 구현해야 함 | 채택 |
| 현행 일괄 연회비 50,000원 유지 | 공개 규정과의 불일치가 남고 규정 변경의 별도 근거가 필요함 | 채택하지 않음 |
| 추가 검토까지 방향 보류 | 현행 동작만 유지하고 목표 기준은 미확정 | 사용자가 방향을 확정함 |

공개 규정을 제품 목표로 삼고 구현을 맞추기로 했다. 현재 코드의 단순한 판정을 근거로 공개 규정 문구를 삭제하거나 고치지 않는다.

## 적용할 규칙

- 회비연도는 1월 1일부터 12월 31일까지다. 평가월까지의 직책상 최소 월회비 누계를 충족하거나 해당 직책의 연납 기준액에 도달하면 권리회원으로 판정한다.
- 같은 회비연도에 여러 직책을 맡으면 가장 높은 회비 기준을 적용한다. 월 약정금액과 권리회원 판정 기준을 구분한다.
- 명예회원은 회비·부담금이 0원이더라도 권리회원으로 자동 전환하지 않는다.
- 환불·배분 취소를 납부 누계에 반영한다. 확정된 과거 권리상태는 규정이 허용하는 정정 사유 외에는 소급 변경하지 않는다. 정정에는 사유와 전후 기록이 필요하다.
- 2026년 적용과 시행 전 확정 상태의 보존은 공개 규정 부칙을 따른다.

| 직책 | 최소 월회비 | 연납 기준 |
|---|---:|---:|
| 회장 | 100,000원 | 1,200,000원 |
| 수석부회장 | 50,000원 | 600,000원 |
| 부회장·감사·총회의장 | 30,000원 | 400,000원 |
| 이사 | 10,000원 | 200,000원 |
| 회원 | 2,000원 | 50,000원 |
| 명예회원 | 0원 | 0원 — 권리회원 전환 대상 아님 |

이 표는 결정 당시 공개 규정의 비교용 발췌다. 이후 회비 기준 개정은 제품 정책과 규정의 권위 있는 개정 근거를 먼저 확인한다.

## 현재 구현과 후속 범위

현재 `server/modules/dues/storage.ts`는 KST 당해년도 `연회비`의 `completed` 합계 50,000원으로 판정한다. 화면과 경조사 호칭은 이 서버 응답을 사용한다. 목표 정책 확정만으로 회원 등급이나 열람·등록 권한을 변경하지 않는다.

후속 구현에는 연도별 회원 직책·변동의 권위와 관리 경로, 납부 귀속월·배분·취소·정정, 확정된 과거 상태 기록이 필요하다. 명부의 자유 텍스트 직책을 검증 없이 판정값으로 쓰거나 기존 `payments` 행에서 없는 사실을 추측하지 않는다. 입회·탈퇴가 연중 발생한 경우처럼 적용 세부가 필요한 항목은 공개 규정과 담당자의 결정 근거를 확인한 뒤 설계한다.

별도 작업에서 데이터 계약과 적용 순서를 정하고 [DB 런북](../runbooks/database-operations.md)에 따라 승인된 환경에만 반영한다. 이 결정의 기록과 등급 계산 코드·DB 적용·운영 배포는 구분한다.
