# ADR 0001: 회원 전용 게시글 통합

- 상태: Accepted — 기존 사용자 확정 결정의 사후 기록
- 기록일: 2026-11-09. 원래 결정일을 새로 추정하지 않는다.
- 정본: [게시글과 경조사 통합](../product/planning-proposal.md#게시글과-경조사-통합), [DB JSON 계약](../reference/database-schema.md#게시글과-경조사-json-계약)

## 배경

일반 게시판, 경조사 `community_events`, 레거시 `obituaries`가 별도 저장·작성·상세 경로를 가졌다. 사용자는 공통 게시판으로 통합하고 출시 전 경조사 테스트 데이터·옛 상세 주소를 폐기하기로 결정했다.

## 결정과 비교한 선택지

`posts`·`categories`를 공통으로 사용하고 모든 posts를 회원 전용으로 한다. 부고·경사는 분류로, 결혼·개원은 경사 사실 JSON의 유형으로 표현한다. `posts.event_data`는 사실 정보를 담고 본문과 구분한다.

별도 경조사·부고 테이블과 상세 폼을 유지하는 기존 방식은 폐기했다. 짧은 텍스트·공개 링크 → 사실 JSON → 필요한 질문 → 미리보기 → 작성자 확인 후 게시를 사용한다. 일반 게시글·댓글·명부를 폐기하는 결정은 아니다. 출시 전 경조사 데이터에 대한 이관·옛 URL 호환도 만들지 않는다.

## 결과와 제약

목록·검색·댓글·첨부·접근 제어를 공통 경로에서 관리한다. 서버는 회원 신원·등록 권한을 결정하며 LLM 해석으로 대신하지 않는다. 공통 본문과 경조사 사실 JSON의 일관성을 유지해야 한다.
