# 역사관 콘텐츠 기준

제품 범위는 [계획서](../product/planning-proposal.md#역사관-콘텐츠-구성-2026-11-10), 실행 환경은 [replit.md](../../replit.md#역사관-개발-범위)를 따른다. 이 문서는 공개 자료의 저장·참조·갱신 계약이다. 관리자 편집·업로드나 DB 저장을 도입하지 않는다.

## 자료와 화면

`shared/heritage/`의 JSON을 타입이 있는 공통 모듈로 읽는다. 화면·메뉴·소개 요약은 같은 자료를 재사용한다. 원천은 사용자가 지정한 [역대회장 명단](https://app.notion.com/p/rapl/7f284ed2f9b74ea59fb77fb16378f64e)과 [연혁](https://app.notion.com/p/rapl/c619eafe4d514df0a22063d90789b70d)이며, 현 임원은 기존 공개 임원 데이터를 사용한다. 홈페이지에서 Notion을 실시간 조회하지 않는다.

| 자료 | 책임 |
|---|---|
| `presidents.json` | 대수·성명·학번·졸업기수·재임 연도. 지정 명단의 연도를 보존하며 기간 겹침·학번과 기수 차이를 추정 보정하지 않음 |
| `timeline.json` | ID·기록일·제목·설명·기사 링크·회장 대수·기부 기록·앨범/문서 ID. 연혁과 기부 목록의 공통 원본 |
| `officers.json` | 대수별 직책·성명·확인된 기수/설명/사진. 현 임원 화면도 같은 자료 사용 |
| `awards.json` | ID·기록일·수여 기관·상명·졸업생 수상자·공적·앨범 ID |
| `albums.json` | ID·제목·기록일·설명·대표 사진 ID·사진 ID 목록 |
| `media.json` | 사진 ID·공개 경로·설명, 문서 ID·제목·공개 경로. 여러 기록에서 ID로 참조 |

기록일은 연도·월·일 중 자료에 있는 범위만 저장한다. 기사 링크의 날짜는 제공된 연혁의 기록일이며 기사 본문에서 행사일을 재확인한 것으로 취급하지 않는다. 기부 금액·주체·목적은 확인된 값만 기록하고 결의와 전달·기탁·기부를 구분한다. 근거가 없는 전체 기부액 합계나 미확인 기부자 이름은 만들지 않는다.

## 사진첩과 자료 연결

- 최근 앨범은 한국 시각의 올해를 포함한 최근 5개 연도다. 연도 필터와 전체 목록을 제공하며 과거 앨범을 삭제하거나 숨겨 보존 기간으로 해석하지 않는다.
- 앨범 ID를 사진첩의 `album` 쿼리로 전달하면 해당 앨범의 사진 목록을 연다. 사진은 기존 Dialog로 확대한다. 뒤로가기와 원래 사진 버튼의 포커스를 유지한다.
- 연혁·수상·기부는 앨범 ID를 참조한다. 기부는 해당 연혁의 앨범 참조를 사용한다. 문서는 해당 연혁에서만 연결하며 같은 파일을 분류별로 복제하지 않는다.
- 사진은 `client/public/images/heritage/`, 문서는 `client/public/documents/heritage/`의 공개 승인된 파일만 추가한다. 기존 회원 업로드 `/objects/`를 공개하거나 Notion의 만료되는 파일 URL을 영구 경로로 저장하지 않는다. 이미지는 설명을 제공하고 지연 로딩한다.
- 사용자가 사진·수상자 자료 반영을 보류했으므로 두 목록에는 임의의 인물·사진·예시 앨범을 넣지 않는다. 자료가 없을 때는 빈 목록 안내를 표시한다.

## 자료 추가와 확인

지정 원천에서 확인한 내용을 해당 JSON에 반영하고 식별자는 유지한다. 사진·문서는 한 번 추가한 뒤 참조 ID로 연결한다. 공개되지 않은 회원 자료·연락처·계좌는 포함하지 않는다. 자료 수정도 소스 변경으로 관리하고 별도 릴리스 요청에 따라 운영에 반영한다.

`node scripts/check-heritage-content.mjs`는 JSON·참조 ID·날짜·공개 파일 경로를 읽는 정적 검사다. 타입·의존 경계·변경 파일 lint와 기존 문서 계약도 필요한 범위에서 Replit 개발 환경에서 확인한다. 실제 화면·사진·외부 기사 조회·DB 호출을 검사하지 않는다.

위 계약은 PR #31로 main과 Replit 운영에 반영했다. 비로그인 HTTP·메타데이터·자산 확인은 [릴리스 기록](../history/heritage-release-2026-11-11.md)을 따른다. 수상자·앨범·앨범 사진·문서가 비어 있으므로 해당 자료의 실제 표시·열람을 확인한 것으로 취급하지 않는다. 반영 자료 수·정적 검사 결과와 미확인 범위는 [역사관 개발 기록](../history/heritage-2026-11-10.md)에 기록한다.
