# 부고문 작성 지침

동국대학교한의과대학동문회 홈페이지에서 부고문을 작성하고 검증할 때 사용하는 기준 문서다.

- 원본: [Notion 부고문 작성 지침](https://app.notion.com/p/39a2225d9c4d80799e4cd4d43ba05021)
- 저장 기준일: 2026-07-11
- 개인정보 처리: 공개 저장소에 실제 연락처와 계좌번호를 남기지 않도록 예시는 가상 값으로 치환했다.

## 목적

부고문 게시 전에 작성자로부터 필수 정보를 받고, 동문회 표준 형식으로 게시문을 생성한다.

## 필수 정보

### 고인

- 이름: `故OOO`
- 나이: `향년 OO세`

### 회원과 고인의 관계

다음 값 중 하나를 사용한다.

- 본인
- 부친
- 모친
- 빙부
- 빙모
- 시부
- 시모
- 자녀

### 장례

- 발인 날짜와 요일
- 장례식장과 빈소 위치

필수 정보가 빠졌다면 게시 전에 작성자에게 보완을 요청한다.

## 선택 정보

- 마음 전하실 계좌: 은행, 계좌번호, 예금주
- 모바일 부고장 URL
- 회원 직함
- 별도의 유가족 연락처

## 회원 정보

다음 정보는 서버의 회원 정보에서 가져오고 작성자가 게시 전에 확인한다.

- 졸업 기수와 학번
- 회원 이름
- 회원 등급
- 휴대전화번호

회원 직함이 있으면 회원 등급 뒤 괄호 안에 표시한다.

```text
김동국 정회원(침구과 교수님)
김동국 회원(동국한의원 원장)
```

## 홈페이지 게시판용 템플릿

```text
#부고
본회 졸업OO기(OO학번) <회원이름> <회원등급>(<선택 직함>) <관계>상

- 고인: 故<고인이름> (향년 <고인나이>세)
- 빈소: <장례식장 및 빈소>
- 발인: <발인날짜(요일)>

- 연락처: <회원이름> <회원휴대전화번호>
- 마음 전하실 곳: <은행> <계좌번호> <예금주>

* 유가족 및 장례식장 위치 확인: <부고장URL>

삼가 고인의 명복을 빕니다.
-동국대학교 한의과대학 동문회-
```

선택 정보가 없으면 해당 줄을 출력하지 않는다. 빈 괄호나 빈 레이블을 남기지 않는다.

## 비식별 예시

```text
#부고
본회 졸업8기(86학번) 김동국 권리회원 부친상

- 고인: 故김한의 (향년 88세)
- 빈소: 동국병원 장례식장 202호실
- 발인: 2026년 6월 12일(금요일)

- 연락처: 김동국 010-0000-0000
- 마음 전하실 곳: 동국은행 000-000-000000 김동국

* 유가족 및 장례식장 위치 확인: https://example.com/obituary

삼가 고인의 명복을 빕니다.
-동국대학교 한의과대학 동문회-
```

## 작성 규칙

1. 필수 정보가 모두 확인되기 전에는 게시할 수 없다.
2. 작성 중인 내용은 회원 계정에 초안으로 자동 저장한다.
3. 작성이 중단되면 마지막 초안을 복구하거나 삭제할 수 있어야 한다.
4. 본인상은 첫 줄을 `#부고 #동문본인상`으로 표시한다.
5. 자동 파싱 결과는 사용자가 확인하고 수정한 뒤 게시한다.
6. 외부 링크를 읽지 못해도 사용자가 붙여넣은 문자 내용으로 작성을 계속할 수 있어야 한다.

## 경조사 통합과의 관계

이 문서는 통합 경조사 기능 중 `부고` 유형의 필드, 검증, 표준 게시문 기준이다. 결혼, 개원, 기타 유형은 공통 초안·게시 구조를 사용하되 별도 작성 지침과 예시를 추가한다.
