# 카카오 동의항목 심사 가이드

## 목적과 적용 상태

이 문서는 카카오 디벨로퍼스 콘솔의 개인정보 동의항목을 현재 구현과 맞추기 위한 운영 가이드다. 현재 코드에는 생일 선택 동의와 카카오 연결 해제를 포함한 회원 탈퇴가 구현돼 있으나, 현재 HEAD의 Replit 전체 자동화 검증, 실제 개발 OAuth·탈퇴 smoke, 실제 화면 스크린샷, 심사용 PDF는 아직 대기 상태다. 대기 항목을 완료한 뒤에만 심사 제출 버튼을 누른다.

## 콘솔 설정값

카카오 디벨로퍼스 콘솔에서 아래 문구를 그대로 사용한다.

```text
이름: 필수 — 졸업생 명부와의 일치 여부 확인 및 동문 자격 인증
카카오계정(전화번호): 필수 — 졸업생 명부와의 일치 여부 확인 및 동문 자격 인증
카카오계정(이메일): 필수 — 회원 식별, 계정 관리 및 동문회 공식 안내
프로필 사진: 선택 — 회원 프로필 화면에 프로필 사진 표시
생일: 선택 — 회원 맞춤형 생일 축하 화면 제공
CI(연계정보): 사용 안 함
```

생일은 `선택 동의`로 설정한다. 동의하지 않아도 가입을 막지 않으며, 생일·생일 유형·윤달 여부가 제공될 때에만 로그인한 본인의 인앱 생일 축하 화면에 사용한다. 공개 생일 목록, 다른 회원 조회, 쿠폰, 카카오 메시지 발송에는 사용하지 않는다.

CI(연계정보)는 사용하지 않는다. 현재 단일 카카오 앱에서 서버가 처리하는 카카오 회원번호, 이메일, 비교용으로 정규화한 전화번호, PostgreSQL 동문 명부의 단일 연결로 중복 가입을 방지한다. CI를 대체 인증수단으로 설명하거나 나중에 수집한다고 표시하지 않는다.

## 서비스 정합성 확인

- 로그인 화면 `/login`에는 필수 `이름, 이메일, 전화번호`, 선택 `프로필 사진, 생일`과 각 목적이 표시돼야 한다.
- 개인정보 처리방침 `/privacy`와 이용약관 `/terms`는 필수·선택 범위, 본인 전용 생일 화면, `내 정보 → 설정 → 회원 탈퇴` 경로를 같은 의미로 설명해야 한다.
- 브라우저에는 카카오 access token, refresh token, 어드민 키, 전체 인가 코드, 카카오 원문 사용자 응답을 노출하지 않는다.
- 회원 탈퇴는 `DELETE /api/users/me`에서 세션 사용자만 대상으로 하며, 카카오 연결 해제 성공 또는 이미 해제된 경우에만 로컬 삭제를 진행한다.

### 제출 전 정합성 보완

현재 `/terms`에는 이전 표현인 `카카오 계정을 통한 간편 가입`이 남아 있다. 현재 구현은 REST OAuth 기반 카카오 로그인이므로, 실제 화면 캡처와 심사 제출 전에는 이를 `카카오 로그인`으로 정리해야 한다. 이 항목은 Task 6의 문서 범위를 벗어나므로 소스는 변경하지 않았으며, 해결 전에는 화면 정합성 검증을 완료로 기록하지 않는다.

## Replit Secrets

카카오 OAuth 환경 변수와 별도로, 실제 연결 해제에는 다음 서버 전용 Secret이 필요하다. 값은 문서, 클라이언트 환경 변수, 로그, 저장소에 기록하지 않는다.

- 개발: `KAKAO_DEV_ADMIN_KEY`
- 운영: `KAKAO_PROD_ADMIN_KEY`

`REPLIT_DEPLOYMENT="1"`일 때만 운영 키를 선택하고, 그 외에는 개발 키를 선택한다. `VITE_` 접두사로 만들지 않는다.

## 심사 전 외부 체크포인트

1. Replit Secrets에 `KAKAO_DEV_ADMIN_KEY`, `KAKAO_PROD_ADMIN_KEY`를 추가한다.
2. 카카오 운영 앱에서 생일을 `선택 동의`와 `회원 맞춤형 생일 축하 화면 제공`으로 설정하고, CI는 `사용 안 함`으로 유지한다.
3. 현재 HEAD를 Replit 개발 워크스페이스에 동기화하고 `npm test`, `npm run check`, `npm run build`를 실행해 각각 종료 코드 `0`을 기록한다.
4. 개발 테스트 계정으로 실제 카카오 로그인, 활동 지역 온보딩, 프로필 표시, 회원 탈퇴를 한 번 수행한다. 탈퇴 뒤 새 연결의 `/api/auth/me` `401`, 사용자·세션 삭제, 명부 연결 해제, 공개 콘텐츠 익명화를 확인한다.
5. `/terms`의 이전 `카카오 계정을 통한 간편 가입` 표현을 REST OAuth 기반 `카카오 로그인`으로 정리한다.
6. `/login`, `/privacy`, `/terms`, 탈퇴 확인 화면을 데스크톱과 모바일에서 개인정보 없는 테스트 데이터로 캡처한다. 실제 화면을 확인한 담당자가 그때만 `docs/review-assets/`에 심사용 PDF를 생성하고 렌더링 검수한다.
7. 운영 Republish 후 운영 로그인·탈퇴는 개발 검증과 분리해 별도 최종 확인한다.
8. 개인정보 국외이전 등록 전에 실제 업체, 국가, 연락처를 확인한다.

이 문서 작성 시점에는 3~7이 완료되지 않았다. `docs/review-assets/kakao-consent-review.pdf`는 생성하지 않았으며, 존재하는 것으로 기록하거나 심사 제출 근거로 사용하지 않는다.
