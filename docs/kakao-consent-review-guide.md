# 카카오 동의항목 심사 가이드

## 목적과 적용 상태

이 문서는 카카오 디벨로퍼스 콘솔의 개인정보 동의항목을 현재 구현과 맞추기 위한 운영 가이드다. 현재 코드에는 생일 선택 동의와 카카오 연결 해제를 포함한 회원 탈퇴가 구현돼 있다. 2026-07-13 기준으로 Replit Development 전체 자동화, 실제 개발 OAuth·명부 매칭·프로필 표시·회원 탈퇴, 운영 additive 스키마, Republish와 운영 비로그인 smoke를 확인했다. 운영 앱의 개인정보 동의항목 심사를 제출했고 카카오 콘솔의 `심사 중` 상태를 확인했다. 심사 승인과 승인 후 운영 OAuth·탈퇴 검증은 아직 남아 있다.

## 콘솔 설정값

카카오 디벨로퍼스 콘솔에서 아래 문구를 그대로 사용한다.

```text
이름: 필수 — 졸업생 명부와의 일치 여부 확인 및 동문 자격 인증
카카오계정(전화번호): 필수 — 졸업생 명부와의 일치 여부 확인 및 동문 자격 인증
카카오계정(이메일): 필수 — 회원 식별, 계정 관리 및 동문회 공식 안내
프로필 사진: 선택 — 회원 프로필 화면에 프로필 사진 표시
생일: 선택 — 회원 맞춤형 생일 축하 화면 제공
CI(연계정보): 사용 안 함
```

생일은 `선택 동의`로 설정한다. 동의하지 않아도 가입을 막지 않으며, 생일·생일 유형·윤달 여부가 제공될 때에만 로그인한 본인의 인앱 생일 축하 화면에 사용한다. 공개 생일 목록, 다른 회원 조회, 쿠폰, 카카오 메시지 발송에는 사용하지 않는다.

CI(연계정보)는 사용하지 않는다. 현재 단일 카카오 앱에서 서버가 처리하는 카카오 회원번호, 이메일, 비교용으로 정규화한 전화번호, PostgreSQL 동문 명부의 단일 연결로 중복 가입을 방지한다. CI를 대체 인증수단으로 설명하거나 나중에 수집한다고 표시하지 않는다.

카카오 로그인 `동의항목 → 대표 채널`에는 운영 앱에 연결된 동문회 카카오톡 채널을 등록한다. 이 채널은 카카오 동의 화면의 대표 채널 표시에만 사용하며, 친구 목록·채널 추가 상태·카카오톡 메시지 접근권한을 요청한다는 의미로 해석하지 않는다.

## 심사 신청 입력값

카카오 디벨로퍼스의 `추가 기능 신청 → 개인정보 동의항목`에서 아래 값을 사용한다.

```text
회원가입 링크: https://dgkma.org/login
개인정보 처리방침: https://dgkma.org/privacy
회원가입 화면 또는 시나리오: docs/review-assets/kakao-consent-review.pdf
```

수집 사유에는 아래 문구를 사용한다.

```text
동문회 회원 가입 및 자격 인증을 위해 이름과 전화번호를 사전 보유한 졸업생 명부와 대조합니다. 이메일은 회원 식별, 계정 관리 및 동문회 공식 안내에 사용합니다. 프로필 사진은 내 정보 표시에, 생일은 로그인한 본인에게만 제공되는 생일 축하 화면에 선택적으로 사용합니다. 선택 항목에 동의하지 않아도 가입할 수 있으며 CI는 수집하지 않습니다.
```

심사용 PDF에는 실제 운영 `/login`의 데스크톱·모바일 화면과 회원가입·명부 매칭·활동 지역 입력·회원 탈퇴 시나리오만 담는다. 회원 이름, 이메일, 전화번호, 카카오 회원번호와 같은 실제 개인정보는 포함하지 않는다.

## 서비스 정합성 확인

- 로그인 화면 `/login`에는 필수 `이름, 이메일, 전화번호`, 선택 `프로필 사진, 생일`과 각 목적이 표시돼야 한다.
- 개인정보 처리방침 `/privacy`와 이용약관 `/terms`는 필수·선택 범위, 본인 전용 생일 화면, `내 정보 → 설정 → 회원 탈퇴` 경로를 같은 의미로 설명해야 한다.
- 카카오가 callback URL의 query로 인가 코드와 state를 전달하고, 브라우저가 인가 코드와 state를 서버에 한 번 전달한다. 서버 응답과 앱 로그에 전체 인가 코드나 토큰을 남기지 않으며, 어드민 키와 카카오 원문 사용자 응답도 반환하거나 기록하지 않는다.
- 회원 탈퇴는 `DELETE /api/users/me`에서 세션 사용자만 대상으로 하며, 카카오 연결 해제 성공 또는 이미 해제된 경우에만 종료 marker와 로컬 삭제를 하나의 트랜잭션으로 기록한다.
- 가입 거절 시 즉시 카카오 연결을 해제한 후 동일 카카오 회원번호 또는 소문자 기준 동일 이메일의 신청정보를 모두 파기하며, 연결 해제 실패 시 거절 미완료로 처리하고 신청정보를 보존한다.
- 종료 marker는 카카오 회원번호와 소문자 이메일의 원문 대신 각각 도메인 분리한 `SESSION_SECRET` 기반 HMAC-SHA-256 identity hash를 저장하며, 각 identity key별 종료 시각의 최신 1건만 보유한다. 종료보다 먼저 시작된 OAuth는 막고 종료 이후 새로 시작한 OAuth는 허용한다.

`/terms`의 이전 `간편 가입` 표현은 현재 구현과 일치하는 `카카오 로그인`으로 정리했으며, 계약 테스트가 해당 표현의 재도입을 차단한다.

## Replit Secrets

카카오 OAuth 환경 변수와 별도로, 실제 회원 탈퇴 및 가입 거절의 카카오 연결 해제에는 다음 서버 전용 Secret이 필요하다. 값은 문서, 클라이언트 환경 변수, 로그, 저장소에 기록하지 않는다.

- 개발: `KAKAO_DEV_ADMIN_KEY`
- 운영: `KAKAO_PROD_ADMIN_KEY`

`REPLIT_DEPLOYMENT="1"`일 때만 운영 키를 선택하고, 그 외에는 개발 키를 선택한다. `VITE_` 접두사로 만들지 않는다.
