# 이전 커뮤니티 로컬 백업 재개 기록

2026-11-14 KST 실행 기록이다. 현재 백업 범위와 절차는 [백업 운영 문서](../runbooks/community-backup.md), 홈페이지 반영은 [이관 기준](../product/community-archive-migration-proposal.md)을 따른다. 이 기록은 원문·SQLite를 Git이나 Replit에 올리는 승인이 아니다.

## 다음카페 백업 완료 정리

2026-11-14 04:24 KST 사용자의 마감 지시를 반영해 다음카페 백업을 **현재 확보된 자료 기준 완료**로 기록했다. 운영 종료 시점까지의 13개 게시판 전체 170건을 저장했으며 미저장 게시글은 0건이다. 일반 글 87건·동창회 앨범 52건·역대 임원진 31건이며 원 첨부 10개도 모두 보존했다.

본문 이미지 위치 444개 중 438개를 저장했다. 저장된 438개에는 원문의 ‘X Image’ 대체 그림 12개가 포함되므로 실제 그림 426개와 구분한다. 미확보 6개는 5개 글에 있으며 수집 당시 실패 사유는 HTTP 415 3개·본문 이미지 주소가 비어 있는 자리 3개다. 같은 날 사용자가 원문에서 **6개 모두 실제 그림이 남아 있지 않음**을 직접 확인했다. 사용자 확인을 새 원격 검사 결과로 대신하지 않으며 누락을 확보 성공으로 표시하지 않는다.

각 누락의 게시판·글 제목·원본 ID·본문 위치·원문 링크·실패 사유·사용자 확인은 Git 제외된 `local-backups/community/daum-dkkmob/backup-completion-2026-11-14.md`에 기록했다. 추가 확인·자동 재시도 대기로 남기지 않고 확보한 원본과 누락 이력을 보존한다.

이번에는 로컬에서 170개 원문 JSON의 기록된 SHA-256, 본문 이미지·첨부 집계와 누락 6개, 저장 미디어 참조 450개 파일의 존재·기록된 크기를 대조했다. 불일치는 0건이다. 미디어 전체 해시는 아래의 01:43 KST 검사 결과를 재사용했다. 문서·로컬 링크 정합성과 `git diff --check`만 추가 확인했으며 원격 재수집·앱 검사·Replit 적용·DB 변경·추가 이관·원복·배포는 수행하지 않았다. 밴드 백업과 두 플랫폼의 마이그레이션 보류는 별도로 유지한다.

## 변환 선택과 이관 전 상태

- 사용자가 지정한 `conversions/rhwp-0.9.0/inputs/dbpl-35.hwpx`를 이관용 파일로 선택했다. 선택 기록·SQLite·실제 파일 해시가 일치한다. ZIP CRC와 XML 읽기를 확인했으며 rhwp 재변환·렌더 대조를 수행한 것으로 보고하지 않는다. 원본 HWP와 기존 rhwp 결과·실패 기록은 유지했다.
- 처음 준비한 일반 게시글 분류안은 앨범형 자료까지 `posts`로 배치하는 잘못된 전제가 있었다. 사용자 정정 후 일반 글 87건·역사관 사진첩 후보 52건·역대임원 자료 검토 후보 31건으로 나눴다. 앨범에 게시글의 이미지 40개 제한을 적용하거나 분할하지 않는다.
- 임원 게시판 1건은 원 카페의 특별회원 열람 제한으로 이관 보류한다. 역사관 후보 83건은 공개 자료 범위 확인 전 반영하지 않는다. 분류한 일반 글 86건도 최종 본문·첨부 변환 및 적용 전 상태다.
- Replit 개발 DB `heliumdb`에서 기존 카테고리와 게시글 1건을 읽기 전용으로 확인했다. PostgreSQL·Object Storage 쓰기, 운영 접근·배포·실계정 QA는 하지 않았다.

로컬 도구의 JavaScript/Python 문법 검사와 문서 `git diff --check`를 수행했다. 애플리케이션 코드를 변경하지 않았으므로 Replit의 앱 lint·빌드·서버 재시작을 추가하지 않았다. 이번 작업에서 commit·push·PR·merge를 실행하지 않았다.
