# 게시글 TableKit 개발

- 목표: 무료 공식 TableKit을 기존 게시글 편집·저장·표시에 연결한다.
- 범위: `@tiptap/extension-table@3.33.0`, 선택 도구의 공식 명령, 공통 스키마·HTML/Markdown·CSS.
- 완료 조건: 로컬·Replit 소스/의존성 일치, 필요한 lint·서식·타입/경계·CSS와 문서 정합성 확인.
- 제외: DB 변경·데이터 변환·브라우저/실계정 QA·서버 재시작·커밋/push·릴리스·유료 기능·새 단축키.
- 검증: 변경 범위에 필요한 정적 검사만 수행하고 실행 확인과 구분한다.

[제품 계획](../product/planning-proposal.md#게시글-본문-서식-2026-11-09), [편집기 계약](../reference/post-editor.md), [DB JSON 계약](../reference/database-schema.md#본문-tiptap-jsonb-계약), [DB 런북](../runbooks/database-operations.md#개발-변경), [Replit 범위](../../replit.md#tablekit-개발-범위)를 먼저 갱신했다.

시작 main은 `b4d55da121f579beba2cb2990e13b525732d3958`이다. 이미지 붙여넣기와 5MB·40개 제한의 기존 미커밋 26개 파일을 보존한다. 표는 기존 JSONB 계약의 확장이며 DB 구조나 기존 행을 바꾸지 않는다.

공식 TableKit의 노드·명령·키 처리·변환과 기존 손실 안내를 재사용한다. 선택한 텍스트 뒤에 기본 표를 삽입하고 표 셀 선택도 선택 도구의 표시 조건으로 사용한다. 상시 서식 도구·맞춤 키 조합·패키지 포크는 추가하지 않는다. 표 격자와 셀 속성은 기존 문서 복잡도 안에서 검사한다.

## 적용 상태

2026-11-12 Replit 개발 워크스페이스에 의존성과 코드를 반영했다. 공식 `@tiptap/extension-table@3.33.0`의 MIT 라이선스를 확인했다. 이번 의존성 설치로 추가된 패키지는 1개이며 기존 Tiptap 버전과 원본 패키지는 수정하지 않았다. 로컬 package/lockfile도 Replit 결과와 맞췄다.

- 공통 `postExtensions`의 TableKit을 편집·저장 정규화·정적 표시·Markdown 변환에 함께 사용한다. 공식 기본 3×3 표 삽입과 행/열 추가·삭제, 셀 병합·분리, 헤더 행/열/셀 전환, 표 삭제 명령을 선택 도구에 연결했다. 단축키는 공식 Tab·Shift-Tab·표 선택 삭제 동작을 유지한다.
- 기존 서식 버튼을 `EditorTool`로 공유하고 표 명령 UI는 `editor-table-tools.tsx`로 분리했다. 텍스트 또는 공식 CellSelection이 있어야 도구를 표시하며, 빈 커서만으로 상시 표시하지 않는다. 삽입 시 선택한 텍스트를 지우지 않고 끝 위치에 표를 넣는다.
- 공식 TableMap의 격자 검사를 재사용한다. `post-table.ts`는 셀 속성과 행별 점유 폭·표 복잡도를 먼저 확인해 임의 배열 속성이나 무제한 병합 크기를 허용하지 않는다. 기존 10,000 문서 복잡도 내에서 병합을 펼친 표 격자 합계를 제한한다.
- HTML 표와 일반 GFM 표를 공식 파서로 처리한다. 공식 표 직렬화의 `<br>` 셀 줄바꿈을 허용하며 그 외 임의 HTML 입력 거부는 유지한다. 병합·너비·복합 셀 내용의 Markdown 손실은 기존 왕복 비교로 안내하고 복사 결과에도 알린다. 보기·복사만으로 JSON 원본을 덮어쓰지 않는다.
- 편집기·상세 표는 같은 CSS와 공식 wrapper로 테두리·헤더·가로 스크롤을 표시한다. 열 크기 조절 핸들은 공식 기본 비활성을 유지한다. 기존 텍스트 추출은 셀의 paragraph 등 내용을 이미 순회하므로 별도 목록/검색 코드나 DB 루틴을 추가하지 않았다.
- 기존 본문·첨부, 5MB·합계 40개, 저장/파일 열람 권한과 경조사 흐름은 보존했다. 표 안의 이미지도 기존 재귀 경로 추출로 개수·권한 검사를 받는다. DB DDL·행 변환·catalog 조회는 수행하지 않았다.

## 미확인 범위와 전달 상태

브라우저에서 표 삽입·셀 선택·Tab 이동·병합·HTML 붙여넣기·Markdown 왕복·모바일 가로 스크롤을 실제 조작하지 않았다. API 저장·DB 조회·수정 화면 재진입 역시 실행 확인하지 않았다. 공식 구현 재사용과 정적 검사 통과는 해당 실행 결과를 대신하지 않는다.

후속 기록만 반영하며 검사한 코드·의존성의 해시는 유지한다. 이전 이미지 작업까지 포함한 최종 소스의 로컬·Replit 대조 결과는 `.superpowers/table-kit-20261112/final-sync.json`에 보존한다.
