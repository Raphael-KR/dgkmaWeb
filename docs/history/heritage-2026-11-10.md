## 승인과 범위

목표는 확정된 연혁·역대회장·역대임원·수상자·기부 내역·사진첩을 공개 홈페이지에 구현하는 것이다. 관련 기준 문서를 먼저 갱신한 뒤 Replit 개발 사본에 반영했다. DB 구조 변경은 필요 시 변경안을 설명하고 승인받는 조건이며, 이번에는 정적 JSON으로 구현해 DB 접근·구조 변경을 하지 않았다.

사진·수상자 자료는 사용자가 “보류. 정리하고 다시 말해줄게”라고 답해 실제 반영을 보류했다. 메뉴와 표시 기능은 구현하고 빈 목록을 유지했다. 운영 배포·실계정 QA·별도 서버 재시작·브라우저·smoke·실행형 기능 테스트는 수행하지 않았다.

## 자료와 구현

- 지정 Notion 회장 명단의 1~22대 이름·학번·기수·재임 기간을 보존했다. 연혁의 회장 섹션이 해당 명단을 참조하도록 수정된 것을 재조회로 확인했다. 6~12대 기간은 명단 기준이며 중첩되는 기간을 추정 수정하지 않았다.
- 연혁 61건을 옮겼다. 기사 링크와 기록일의 연·월·일 정밀도를 유지했다. 기사 본문의 행사일을 따로 조회·검증하지 않았다.
- 임원은 연혁의 제5대 14명과 기존 공개 화면의 제22대 18명을 공통 자료로 묶었다. 현 임원 화면의 이름·직책·사진·설명도 같은 자료를 사용한다.
- 기부·기탁·전달·찬조 결의 13건은 11개 연혁 기록 안에 저장하고 기부 화면에서 재사용한다. 결의를 실제 납부로 바꾸거나 불명확한 기부 주체·전체 합계를 만들지 않았다.
- 사진첩은 한국 시각의 올해 포함 5개 연도·전체·이전 연도 탐색, 링크로 여는 앨범 상세, 기존 Dialog를 이용한 사진 확대를 구현했다. 연혁·수상·기부는 앨범 ID를 공유하고 문서는 연혁에서 참조한다.

- 소개 페이지의 연혁 요약은 같은 연혁 자료를 사용한다. 기존 소개에 있던 2000년 사무국·2015년 학술대회·2025년 플랫폼 출범 문구는 제공 자료에서 확인되지 않아 확인된 기록으로 교체했다.
