## 도구와 자료 계약

Git 제외된 `local-backups/community/tools/`의 migration-preview.py, prepare-post-migration.py, apply-post-migration.mjs, record-cafe-application.py를 수정했다.

- 분류는 원본 index·SQLite 원본 ID/해시와 확정 목적지에 기반한다. 과거 적용 상태는 참고 이력으로만 보존한다. 86건 고정 검사와 classified-not-applied 상태 필터를 제거했다.
- 원문 본문에 작성자·날짜·출처 문단을 합성하지 않는다. authorId=NULL, authorName과 importData를 별도 필드로 준비한다. 실제 importedAt과 행 생성 시각은 적용 시 채우며 published_at은 UTC로 명시 변환한다.
- 같은 원본 ID·입력 해시·캐시 결과 해시·참조 파일 해시이면 문서를 재사용한다. 재사용 대조에서 첨부 목록 순서가 바뀌던 문제를 정렬로 수정한 뒤 같은 입력의 posts.json 해시 일치를 확인했다.
- 적용 도구는 본문 링크 대신 import_data의 플랫폼·컨테이너·원본 ID로 중복을 판별한다. 로컬 기록에 연결된 과거 개발 테스트 행은 자동 덮어쓰기·삭제하지 않고 충돌로 보고한다. 영수증은 실행마다 별도 파일로 남기고 기록 도구는 명시적으로 지정된 영수증과 payload 해시를 대조한다. 적용·기록 도구는 실행하지 않았다.
