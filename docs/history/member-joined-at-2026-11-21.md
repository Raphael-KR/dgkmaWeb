# 개발 회원 가입일 기록

2026-11-21(KST) Replit 개발 워크스페이스에서 [가입일 DDL](../../scripts/add-member-joined-at-development.sql)을 적용했다. `heliumdb`의 기존 회원 3,458행에 대해 nullable `TIMESTAMPTZ` 한 컬럼만 추가했다. 기존 행을 갱신하는 SQL은 실행하지 않았다. 새 연결에서 같은 3,458행 중 `joined_at`이 채워진 행은 0건이었으며 컬럼에 기본값이 없음을 확인했다.

자동 가입 및 관리자 최초 승인 트랜잭션이 가입일을 기록한다. 승인 취소·재승인은 원래 값을 보존하며, 기존값이 NULL인 테스트 계정도 같다. 내 정보와 관리자 인증 완료 목록에서 날짜를 한국 시간으로 표시하고, NULL은 ‘기록 없음’으로 표시한다. 신청 대기·거부 목록은 신청일을 사용한다.

개발의 metadata-only catalog에서 읽기 전용 대상 확인·ROLLBACK·완료 표식을 확인했다. public 컬럼은 119개에서 120개로 늘었다. catalog SHA-256은 `a1c227b40890723633e236316145b60927b85bc3d53fb2e51d85f1414c2626b1`이다. 운영 DB와 배포, 실제 가입 및 실계정 QA는 보류했다.

Replit에서 변경 TS·TSX 파일 ESLint·Prettier, 앱 타입·브라우저/서버 의존 경계(283개 파일), 테스트 코드 타입과 Git diff 검사를 통과했다. 기능 테스트나 가입을 실행하지 않았다.
