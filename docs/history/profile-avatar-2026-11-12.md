## 원인과 수정 범위

[공통 Avatar](../../client/src/components/ui/avatar.tsx)의 이미지는 `h-full w-full`로 크기를 고정했지만 `object-fit`이 없어 직사각형 사진을 늘여 표시할 수 있었다. [내 정보](../../client/src/features/profile/profile.tsx)는 이 컴포넌트를 정사각형으로 사용하고 있다.

이미지에 `object-cover object-center`를 적용해 원본 비율을 보존하며 중앙을 채운다. 기존 `rounded-full overflow-hidden` 마스크와 사진이 없거나 로드되지 않을 때의 대체 표시는 유지한다. 첨부한 가이드의 28px는 이미지 제작 여백이므로 렌더링 패딩으로 추가하지 않는다. 회원 API의 기존 사진 주소를 사용하며 카카오 원본을 새로 내려받거나 가공하지 않는다. [공통 표시 정책](../product/planning-proposal.md#공개-홈회원-커뮤니티의-공통-표시-2026-11-09)을 먼저 갱신했다.

## 회원 인증 배지 정리

후속 사용자 결정으로 홈·내 정보의 `인증완료`·`인증대기` 배지를 제거한다. 기존 일반회원·권리회원·관리자 표시, 사진 크롭·내 정보 연결은 유지한다. 가입 승인 대기 목록과 명부 연결·미연결 통계는 기존 관리자 화면을 사용한다. 회원 판정 데이터·가입 로직·권한 검사·DB·운영 배포는 변경하지 않는다.

완료 조건은 두 화면의 인증 배지 제거와 Replit 개발 사본의 변경 파일 lint·서식 통과다. 타입 계약·컴포넌트 API를 바꾸지 않는 JSX 제거이므로 전체 타입·테스트·빌드를 반복하지 않으며, 문서 링크·공백과 기존 변경 보존을 확인한다.
