# 인증·명부·관리자 책임 분리 기록

## 승인 범위

- 목표: 앞선 코드 검토에서 지적한 큰 책임 묶음·압축 코드·오래된 주석을 정리한다.
- 범위: 인증·명부 저장·관리자 화면, 경조사 수정과 공개 수집 코드, 관련 주석·소스 계약·기준 문서.

- 검증: Replit 타입·의존 경계·변경 파일 ESLint, 필요 시 테스트 타입 및 파일만 읽는 계약 검사, 문서 링크와 diff 확인.

실제 수행한 정적 검사:

- Replit `npm run check`: 앱 타입 및 의존 경계·runtime import cycle 검사 통과(앱 232개 파일). 첫 타입 검사에서 발견한 OAuth 프로필의 optional 필드를 기존 필수·nullable 계약으로 바로잡은 뒤 통과했다.
- Replit `npm run check:tests`: 분리된 storage·인증 export와 기존 테스트 타입 호환성 통과. 테스트 실행을 뜻하지 않는다.
- Replit ESLint: 변경된 JS/TS 45개 파일 통과. 이후 타입을 수정한 `kakao-profile.ts`만 다시 확인해 통과했다.

- Replit TypeScript 구문 트리 대조: 명부 메서드 16개의 본문과 트랜잭션, 인증 라우트 등록 순서 8개와 이동한 핸들러 7개, OAuth 상태·provider 검증·가입 분기, 관리자 mutation·query·표시 카드가 보존됨을 확인했다. 서식 정리 11개와 주석만 바꾼 5개 파일도 원본과 구문 트리가 같았다. 이 검사는 앱 함수를 실행하지 않았다.
