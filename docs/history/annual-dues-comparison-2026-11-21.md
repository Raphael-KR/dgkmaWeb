# 2026년 11월 21일 권리회원 판정 대조

사무국 명단 223명 전원을 Replit 개발 명부의 서로 다른 동문 ID와 연결했다. 한국 시간 11월 21일까지 입금된 2026년도 회비와 같은 해 맡은 최고 직책을 기준으로 개발 판정 함수를 실행했다.

| 사무국 납부 상태 | 인원 | 규정 기준 충족 | 미충족 |
|---|---:|---:|---:|
| 완납 | 102 | 102 | 0 |
| 일부 납부 | 28 | 2 | 26 |
| 미납 | 93 | 0 | 93 |
| 합계 | 223 | 104 | 119 |

연납 기준을 충족한 사람은 62명, 연납액 미만이면서 11월까지의 최소 월회비 누계를 채운 사람은 42명이다. 일부 납부자 중 2명은 각 30,000원을 납부해 일반회원의 11월 최소 누계 22,000원을 넘겼다. 사무국에서 적용한 개인별 기준은 각각 50,000원과 33,000원이었다. ## 대조 범위

- **신원과 입회일.** 기준일까지 실제 입금한 157명의 확정 연결을 재사용했다. 추가 66명 중 60명은 과거 원장과 명부, 6명은 명부의 기수·성명으로 확인했다. 미확인·중복은 각 0명이다. 명단의 졸업일 220개를 판정 입력에서 확인했다. 대학원 동문 3명의 졸업일은 미상으로 두었다. 223명 모두 기준일 입회가 확인된 동문으로 판정했다.
- **납부.** 개발 원장의 회원별 배분을 귀속연도와 실제 입금일로 조회했다. 명단 안의 130명에게 배분된 632건·6,565,000원은 사무국의 개인별 금액·횟수와 전부 일치했다. 명단 밖의 2026년 귀속 개인 납부는 0건이다. 성명불상 1건·2,000원은 원장에만 남는다. [개발 원장 이관 기록](dues-ledger-development-2026-11-21.md)
- **직책과 명예회원.** 223명은 사무국이 회비를 부과한 동문이다. 제21·22대 임원 기록과 대조해 그해 전임 회장과 전임 이사 각 1명에게 더 높은 요율을 적용했다. 두 사람 모두 미충족이었다. 전체 명부의 명예회원 여부를 일괄 확정하지 않았다. [제36차 정기총회](https://app.notion.com/p/3152225d9c4d80658b1bf953f0e794ad) · [제22대 임원](https://app.notion.com/p/5b30b057ceee40d995aa046c12b76e2a) · [2026년 요율표](https://docs.google.com/spreadsheets/d/1aStEZeCSHIUqS4W81umlW8B3pMCJpx-u5Oe_IHcD49k/edit#gid=379091912&range=O16:O21)
- **실행 환경.** Replit 개발 판정 함수에서 명단 등재일 자동 인정을 제거하고 ESLint와 `npm run check`를 통과했다. 개발 DB는 읽기 전용으로 조회했다. Replit의 판정 코드와 의존성을 로컬에서 실행해 비공개 명단과 대조했다. 이번 대조는 11월 21일에 한정하며, 홈페이지 전환 시점은 사무국이 검토한다. [연도별 판정 설계](../product/annual-dues-database-design.md)

## 개발 판정 함수의 날짜·재입회 검사

2026년 11월 21일 Replit 개발 워크스페이스에서 실제 판정 함수에 가상 입력을 메모리로만 전달했다. 21개 사례에서 자격·사유와 해당 연도 누계가 기대값과 일치했다.

| 검사 | 사례 | 확인한 결과 |
|---|---:|---|
| 월 10일·11일 | 7 | 10월 말 권리가 확정된 회원은 11월 10일까지 유예를 받고 11일부터 당월 누계를 적용받는다. 12일의 납부는 12일부터 인정한다. 전월 말 자격이 미확인이면 당월 기준 충족 또는 추가 근거가 필요하다. |
| 연도 경계 | 7 | 12월 말 권리는 1월 1~10일에 이어진다. 전년도 귀속 납부는 새해 누계에서 제외한다. 1월 11일에는 새해 회비 기준이 필요하며, 그해 요율이 없으면 확인 필요로 판정한다. |
| 탈퇴·같은 해 재입회 | 7 | 탈퇴일부터 재승인 전날까지 권리를 중지한다. 재승인일부터 다시 연결한 당해 납부를 인정하며 최소 월회비는 1월부터 계산한다. 이전 회원 기간의 유예는 승계하지 않는다. 납부 연결이 미확인이면 확인 필요로 둔다. |

개발 DB를 읽기 전용으로 확인한 결과, 탈퇴원 접수와 같은 해 재입회 이력은 각각 0건이었다. 요율·직책·자료 확인 범위·확정 자격 테이블은 설계 단계로, 월말 자격 저장이나 재입회 납부 재연결을 실제 DB에서 검증한 결과는 없다.
