# 미사용 경로·설정과 문서 정리

2026-11-10 사용자 승인 범위의 작업 기록이다. 제품·구조·환경 기준을 먼저 갱신한 뒤 개발 사본에 적용했다. 현재 기준은 [제품 계획](../product/planning-proposal.md), [구조](../architecture/project-structure.md), [Replit](../../replit.md)을 따른다.

## 승인 범위와 완료 조건

- 열기 경로 없는 회원 사이드 메뉴, 루트 Typography 플러그인, 기품 구형 수집 경로, 소비하지 않는 `dateOfDeath` 계산, 읽히지 않는 SEO 설정, 임시 관찰 `origin` 속성을 정리한다.
- DB 기준서·런북의 완료 작업 설명을 이력 링크로 줄이고, Object Storage 메모를 현행 코드·보안 기준에 연결한다.
- Umami는 외부 주입 여부를 확인한 뒤 미사용일 때 helper·호출부를 제거한다. 확인되지 않은 부분은 미확인으로 남긴다.
- 기존 회원·관리자 권한, 수집 URL·응답 검증, 실제 별세일과 필드별 출처, 저장 규칙 호환을 유지한다. sandbox·기존 미커밋 작업은 보존한다.
- Replit 개발 사본 적용 후 필요한 타입·의존 경계·변경 파일 lint와 문서 링크·해시를 정적으로 확인한다. 실제 수집·LLM·단위/통합 검사·DB·배포·실계정 QA는 실행하지 않는다.

## 적용 상태

기준 문서 9개를 먼저 Replit 개발 사본에 반영했다. 기존 파일 해시를 비교한 뒤 적용했으며 다른 변경을 덮어쓰지 않았다. 그 뒤 아래 코드·문서를 정리하고 필요한 정적 검사를 수행했다. 모두 미커밋 개발 작업 사본의 변경이며 운영 게시 상태를 갱신하지 않는다.

| 항목 | 실제 반영 |
|---|---|
| 회원 사이드 메뉴 | 열기 경로 없는 `navigation.tsx`와 전용 상태·관리자 메뉴 항목을 제거했다. 회원 상·하단, 공개 서랍, 회원 홈 관리자 진입은 유지했다 |
| Typography | 루트 플러그인 등록·직접 의존성과 전용 전이 의존성 3개를 정리했다. Replit에서 `npm uninstall @tailwindcss/typography --package-lock-only --ignore-scripts --offline --no-audit --no-fund`를 사용했다. 나머지 잠금 패키지의 변경·추가는 0개이며 기존 설치 패키지는 건드리지 않았다 |
| 기품 수집 경로 | 구형 함수·도달 불가능한 기본 분기를 제거했다. 기존 읽기 대역을 `readGipoomNotice`의 선택 인수로 연결해 현재 URL·응답 검증과 Python 선택 경로를 사용한다. 기존 5개 검사와 입력 자료를 유지하며 검사 대상을 현행 경로로 바꿨다 |
| 구형 별세일 계산 | 소비하지 않는 `dateOfDeath` 프로퍼티·전용 함수·패턴만 제거했다. 공통 `deathDate` 추출과 원문은 유지했다 |
| SEO | 선행 회원용 반환에 가려진 `/b`·`/search` 설정과 중복 조건만 제거했다. noindex·옛 주소 노출 차단·canonical은 유지했다 |
| JSON 관찰 속성 | 소비하지 않는 임시 `origin` 타입·할당 4곳을 제거했다. 실제 필드 출처와 저장 규칙의 JSONB 계약은 유지했다 |
| DB 문서 | 완료된 소스 정리 설명을 이력 연결로 축소했다. 현재 구조·마지막 catalog 관찰·게시글 보존·권리회원 목표와 현행 차이는 유지했다 |
| Object Storage 메모 | 옛 blueprint 설명을 과거 배경으로 구분하고 현행 라우트·경로 문법·열람 권한·보안 기준에 연결했다 |

기품 검사 파일은 앞으로 실행할 때 기존 입력 자료를 현재 Python bridge에도 전달한다. 이번에는 타입만 확인했으며 검사 사례나 Python 작성기를 실행하지 않았다. 신규 합성 자료·DB는 만들지 않았다.
