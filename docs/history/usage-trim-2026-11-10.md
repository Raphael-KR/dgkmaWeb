# 미사용 분기·필드와 최근 글 표시 정리

2026-11-10 사용자 승인 범위의 작업 기록이다. [제품 계획](../product/planning-proposal.md), [구조 기준](../architecture/project-structure.md), [Replit 운영](../../replit.md)에 변경 기준을 먼저 반영한 뒤 로컬·Replit 개발 사본에 적용했다.

## 범위와 보존 계약

| 항목 | 변경 | 보존 |
|---|---|---|
| 로그인 실패 분기 | 앞선 가입 심사에서 처리되어 도달하지 않는 마지막 사용자 부재 분기 제거 | 실제 충돌·alumni_race 심사, OAuth generation·종료 marker·잠금·세션 확정 |
| 파서 직함 선언 | 생성·소비되지 않는 details.memberTitle만 제거 | 공통 NoticeFacts.memberTitle과 실제 직함 문안, staticHints의 다른 필드 |
| 두 줄 말줄임 | 중복 수동 CSS를 제거하고 Tailwind 기본 line-clamp-2 사용 | 세 화면의 기존 클래스와 Tailwind 구성 |
| 업로드 PUT 응답 | 본문 없는 HTTP 200으로 축소 | POST의 objectPath, 실제 저장, 세션·크기·MIME·서명·만료·첨부 권한과 실패 JSON |
| 신원 해시 인수 | 미사용 Secret 인수 제거, helper에서 호출 시 키 해석 | HMAC-SHA256, 종류 구분 문자열, 이메일 정규화·호출 시점 키 해석 |
| 헤더 표시 | 고정 빨간 점 제거, 목록 아이콘과 ‘최근 글’ 이름·툴팁 적용 | 홈 이동·최근 글 스크롤, 기존 회원 메뉴·검색·로그아웃 |

완료 조건은 위 범위의 로컬·Replit 개발 반영, 필요한 앱 타입·lint·CSS 구문·문서 정적 검사와 보존 확인이다. DB 구조·데이터, Secrets, 기존 권한·보안 경계를 변경하지 않는다. 실행형 검사·HTTP·브라우저·빌드·서버 재시작·배포·실계정 QA·Git 게시는 포함하지 않는다.

## 적용·검사 상태

2026-11-10 Replit 개발 워크스페이스에서 다음 정적 검사를 수행했다.

| 검사 | 결과 |
|---|---|
| `npm run check` | TypeScript 및 앱 221개 파일의 의존 경계·순환 검사 통과 |
| 변경한 TS·TSX 5개 파일 ESLint | 오류·경고 없음 |
| `client/src/index.css` PostCSS 구문 분석 | 통과 |
| 문서 경로·앵커 확인 | Markdown 80개, 내부 링크 727개·앵커 259개에서 오류 없음 |
| `git diff --check` | 로컬·Replit 통과 |

이번 작업은 기존 파일 10개 수정과 이 기록 1개 추가다. 코드 변경은 표의 6개 항목에 한정했으며, 작업 시작 시 존재한 나머지 487개 파일과 기존 미커밋 변경은 그대로 보존했다. 테스트·DB·패키지·sandbox 파일은 변경하지 않았다. 해시 대조로 로컬·Replit의 관리 대상 파일 498개가 같음을 확인했다.

로그인 충돌·세션 확정, 해시 알고리즘·입력 정규화, 업로드 검증·오류 처리와 최근 글 이동 순서는 변경 전 코드와 직접 대조했다. 공통 `NoticeFacts.memberTitle`과 기존 `line-clamp-2` 사용처를 유지했다. 이는 정적 보존 확인이며 실제 로그인·업로드·화면 동작 검사 결과는 아니다.

코드·문서는 미커밋 상태다. 로컬 HEAD `d7184ca`, Replit HEAD `5872027`은 변경하지 않았다. 테스트 코드를 바꾸지 않아 `check:tests`는 추가하지 않았으며 실행형 테스트·DB 작업·HTTP 호출·빌드·서버 재시작·배포·실계정 QA·Git 게시는 수행하지 않았다.
