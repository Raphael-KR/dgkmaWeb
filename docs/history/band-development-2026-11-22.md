# 밴드 개발 이관 준비와 원작성자 실명 대조

대상은 한국 시간 2026년 11월 20일까지 로컬에 백업한 동문회 밴드다. 11월 21~22일에 원본 식별자 기준으로 분류표를 작성하고 Replit 개발 명부로 작성자를 대조했다. 아래 건수는 운영 이전이나 게시글 발행 건수가 아니다.

최초 분류에서 목적지 미정으로 집계한 6,401건을 당시 분류기의 조건으로 재현해 원본 ID별로 현재 분류표와 대조했다. 이 중 일반 게시글은 6,252건이다. 본문에 해시태그가 있는 639건 중 217건은 목적지 태그로 분류했다(자유 202, 소식 14, 경사 1). 다른 태그만 있는 422건은 본문과 백업된 첨부를 검토해 자유 228건, 소식 104건, 행사 40건, 공지 32건, 경사 10건, 부고 6건에 배정했다. 420건의 게시판을 확정하고 2건을 제외했다. 트레킹 행사 모자 사진은 당시 학장의 협찬 기록으로 확인해 소식에 포함했다. 대화 캡처 글과 종속 댓글 4건, 동문교류회 앨범 생성 안내글은 이관 대상에서 제외했다. 독립 앨범 사진 32장의 파일 크기와 해시를 대조했으며 안내글의 미리보기 3장은 이 32장에 포함된다. 최초 집계의 나머지 149건은 이후 자동 안내로 확인했다.

자동으로 자유에 배정했던 5,638건(위 422건과 별도)의 본문·첨부를 재검토했다. 자유 5,171건, 소식 252건, 행사 113건, 공지 69건, 부고 13건, 경사 11건으로 결정하고 플랫폼 자동 안내 8건과 개인 대화 캡처 1건을 추가로 제외했다. 일정 생성 안내 17건은 회원이 작성한 행사명·시점·기록을 확인해 행사 12건과 소식 5건으로 배정했다. 검토표는 각 원본 식별자·해시 및 판단 근거와 함께 비공개 로컬 자료에 보관했다.

밴드가 자동 생성으로 표시한 532건은 가입 안내 507건(댓글·답글 822건)과 기타 알림 25건(댓글 60건)이다. 표식이 없는 구형 자료에서도 가입 안내 정형 문구와 일치한 146건(댓글·답글 399건), 원문 전체와 표시 유형·첨부가 생일·프로필 변경·앨범 생성 양식에 일치한 20건(댓글 92건)을 확인했다. 가입 안내 총 653건과 댓글·답글 1,221건을 이관 기준에 포함했다. 생일·밴드 기념일·프로필 변경·앨범 생성 알림 45건과 댓글 152건은 로컬에 보존한다. 가입 안내 중 실명·본문·첨부와 상위 글 연결 요건까지 충족한 자료는 원글 152건과 댓글·답글 104건이다. 제외된 2016 정기총회 앨범 생성 알림의 앨범 ID로 사진 86장의 크기와 해시를 확인했다. 별도 카드의 가입 환영 108건은 당시 밴드가 작성한 기록으로 자유 게시판에 배정했다. 기념일·미션 4건은 제외했다. 카드별 게시 자료 작성과 미확인 표시명 처리는 남아 있다.

독립 사진첩 11개에 속한 사진 395장과 백업에서 원글을 찾지 못한 사진 7장을 구분했다. 댓글에만 있던 사진 383장, 동영상 4개 및 스티커 참조 1,423건은 실물 파일을 확인하지 못했다. 실물이 있는 댓글 파일 2개는 일반 파일 48개에 포함된다. 게시글 본문 7,468건은 텍스트로 변환했고, 첨부만 있는 글은 97건이다. 복사 제한 3건과 민감한 URL 검토 2건의 본문은 후보에서 보류했다.

## 실명

밴드 작성자 키별로 본인 프로필에 적힌 성명·졸업기수를 개발 기본명부와 대조했다. 원본 계정과 홈페이지 계정을 연결하지 않았다. 동명이인, 이름·기수 미기재, 명부 불일치는 사무국 확인 대상이다.

| 구분 | 전체 | 실명 확인 | 확인 대기 |
|---|---:|---:|---:|
| 고유 작성자 키 | 738 | 234 | 504 |
| 게시글 | 7,570 | 4,477 | 3,093 |
| 댓글·답글 | 7,920 | 4,097 | 3,823 |

원글 4,477건은 명부 대조 4,476건과 사무국이 특정 글의 작성자로 확인한 1건을 합한 수다. 원글·상위 댓글 작성자까지 모두 확인한 댓글은 2,601건(원댓글 2,598·답글 3)이다. 확인 대기인 작성자 키 504개는 이름·명시 기수 근거 부족 421개, 삭제된 프로필에서 두 정보를 확보하지 못한 경우 41개, 해당 조합 명부 미등록 37개, 프로필 정보 모호 4개, 명부에서 같은 성명·기수 중복 1개다. 확인 대기 댓글 중 한 건은 원문에 작성자 키가 없다. 실명표는 Git에서 제외한 로컬 폴더 안에 파일 권한 0600으로 보관한다.

## 개발 DB와 코드

실명·분류·본문·첨부·상위 글 연결을 함께 검산한 결과 게시글 4,147건과 댓글·답글 1,673건을 이관 후보로 선별했다. 원글에 올릴 일반 첨부와 댓글 첨부 참조는 합계 3,943개다. 목적지를 정한 원글 중 개인정보 검토 26건과 외부 접속정보 검토 3건을 발행 후보에서 보류했다. 목적지 미정은 0건이다. 실명·본문·첨부 등의 조건으로 보류된 원글은 총 3,367건이다. 확보한 영상 163개 중 이관 후보 글 84건의 MP4 101개(1,940,433,138바이트)를 회원 열람용으로 포장했다. 나머지 62개도 로컬 백업에 있다. 이 단계에서 개발 저장소에 업로드하거나 밴드 글·댓글을 발행한 건은 없다.

개발 DB `heliumdb`에 [댓글 전환 SQL](../../scripts/add-band-comment-source-development.sql)을 적용했다. 새 연결에서 댓글 컬럼 9→12개, 상위 댓글 참조·출처 검증 제약 및 고유 인덱스를 확인했다. [스키마 기준서](../reference/database-schema.md#table_row-comments)에 카탈로그 지문을 기록했다. 기존 다음카페 글 80건, 밴드 글 0건, 댓글 0건을 확인했다. 개발 사진첩 카탈로그는 앨범 52개·사진 항목 406개였다.

개발 워크스페이스에서 댓글·답글 표시, 이관 전용 첨부와 동영상 열람 코드의 TypeScript와 모듈 경계 검사를 통과했다. 변경된 JS·TS 소스의 ESLint·Prettier 검사와 Python 파일 13개의 구문 검사도 통과했다. 원글 84건의 영상을 비공개 저장소에서 실제 재생하는 검사는 개발 데이터 반영 이후에 한다. 실계정 QA와 운영 변경은 수행하지 않았다. 밴드 마지막 게시일과 전환일은 개발 이관 결과를 검토한 뒤 정한다.

## 11월 24일 성명 우선 대조

11월 20일 마감 백업을 대상으로 Replit 개발 명부를 읽기 전용으로 대조했다. 성명으로 한 사람을 확인한 밴드 계정은 538개, 동명이인 중 기수로 한 사람을 확인한 계정은 42개다. 전체 738개 중 580개를 확정했다. 가입 댓글까지 반영한 종전 대조보다 238개 늘었으며 보류는 158개다.

이관 대상 원글 7,514건 중 6,959건, 댓글·답글 7,759건 중 6,251건의 실명을 확인했다. 상위 글 또는 댓글의 작성자까지 확인한 댓글·답글은 5,572건이다. 본문·첨부 조건을 함께 적용한 로컬 이관 후보는 원글 6,393건과 댓글·답글 3,853건이다. 변경된 실명표를 입력으로 준비·후보 집계를 재생성했다. DB 데이터 이관, 파일 업로드와 배포는 수행하지 않았다.
