## 후보와 검사

기존 시트 동기화 화면·API·전용 검사와 공유 타입을 제거하고, 가입 심사 기록·기존 명부 테이블과 최초 자료 반영 CLI를 보존했다. 관리자 회비 조회 경로를 기존 접근권한 회귀 검사에 추가했다. 개인 회계 감사 PDF·PNG와 macOS 부속 파일은 릴리스에서 제외했다.

Replit에서 ESLint, 변경 소스 Prettier, 앱·테스트 타입 검사, 클라이언트 의존 경계, 최종 빌드를 통과했다. 일반 회귀는 234건 중 224건 통과·실패 0건이었다. 전환 미들웨어 추가 후 영향받은 회귀 11건이 통과했다. 빌드한 서버 파일의 SHA-256은 `4d4e7bafd1723849081c8e2911ecf1b3f0551d22d95145d72a563d73385cc08e`다.

일반 회귀에서 제외한 10건은 승인 후 개발 DB에서 별도로 확인했다. 8건은 기존 검사 그대로 통과했고, OAuth 2건은 시험 중 발급한 값에만 만료 정리를 한정해 동시 소비와 탈퇴 후 콜백 차단을 확인했다. 기존 만료값 2건의 내용은 같았고 임시 레코드는 남지 않았다. 전체 만료값 일괄 정리와 실계정 QA는 수행하지 않았다.

승인된 명부와 필수 구조를 한 트랜잭션에서 적용했다. 커밋 전과 커밋 후 새 연결에서 명부 3,461명·별칭 2건을 확인했다. 미가입 3,362명, 사망 95명, 가입 완료 4명이며 기존 관리자 1명, 심사 1건, 게시글 80건을 보존했다. 기존 가입일과 변동 이력은 소급하지 않았다.
