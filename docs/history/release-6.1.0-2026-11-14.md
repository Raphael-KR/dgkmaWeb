# 6.1.0 릴리스 — 2026-11-14

## 후보와 범위

기준 운영 소스는 v6.0.0의 86b1142이며 공유 main은 9201880이다. 사진첩 회원 전용 API·비공개 목록, 역대임원 공개 자료, 계정 없는 글 표시와 문서 정리를 포함한다. 기능 개선으로 MINOR를 선택한다. 운영 데이터 이관·DB 변경·Secrets 변경·실계정 QA는 포함하지 않는다.

## 정리와 검사 선택

공개 albums/media JSON과 import를 제거하고 documents JSON·회원 API 소비자로 연결했다. 공개 기록은 앨범 제목 대신 ID 링크를 유지한다. 카탈로그를 공개 번들에 넣지 않고 기존 회원 승인 가드·Object Storage 다운로드·로그 경로를 재사용한다. 원본 백업·SQLite·변환·영수증은 Git 제외된 로컬에 보존한다. 기존 게시글 JSONB와 작성자 NULL 읽기, 회원·첨부 권한은 유지한다.

공통 검사: 변경 JS/TS lint·서식, 앱 타입/경계, 배포 빌드, 문서·diff 확인. 선택 검사: 공개 역사 자료, 파일 전용 사진첩 카탈로그, 개인정보 로그 소스, 권한 HTTP·승인 가드. 라우터 자체 변경·DB 구조 변경은 없어 전체 회귀·DB 검사는 선택하지 않는다. 기존 검사 목적과 이번 영향이 일치하며 삭제·통합할 중복 검사는 확인되지 않았다. 회원 사진첩의 실제 로그인·다운로드·화면은 미검증으로 남긴다.

## 실행 결과

Replit 개발 환경에서 변경 JS/TS lint·명시적 파일 서식 검사, `npm run check`(앱 277개·경계 포함), `node scripts/check-heritage-content.mjs`, 권한 HTTP·승인 가드·개인정보 로그 12건, `npm run build`를 통과했다. 최초 서식 호출의 파일 선택 오류는 명시적 목록으로 수정해 재검사했다. 로컬 스킬 형식 검사와 문서 정합성·링크·`git diff --check`도 통과했다. 로그는 Git 제외된 `.superpowers/release-checks.log`다.

검사용 회원 카탈로그를 Replit 임시 경로로 전송하려던 명령은 자동 승인 검토가 사적 자료 반출로 거절하여 실행하지 않았다. 추가 전송 없이 기존 2026-11-14 개발 카탈로그 정적 검사와 입력 해시를 대조해 재사용 여부를 판정한다. 이 릴리스는 운영 카탈로그를 이관하지 않는다.

로컬/Replit 변경 코드·공개 자산은 사전 파일 해시가 일치했고, 최신 문서를 직접 반영해 후보를 맞췄다. 원문 백업·SQLite·캐시·빌드 산출물은 제외했다. 게시판·사진첩의 실제 로그인/다운로드·화면·실계정 QA는 미실행이다.
