2026-11-11 사용자가 별도로 요청한 이번 전수 정리는 프로젝트 전체 검사·명령·설정·CI와 관련 문서를 대상으로 한다. 제거·통합·축소 후 사용처와 보호 범위를 다시 검토하고, 자율적으로 처리할 근거가 있는 추가 후보가 없는 전체 검토 회차에서 종료한다. 사용자 결정이 필요한 항목은 [전수 정리 기록](check-audit-2026-11-11.md)에 모아 독립 작업을 마친 뒤 질의한다. 이 범위를 매 개발·릴리스의 반복 전수 검사로 확대하지 않는다. 앱 동작·권한·보안·저장 호환성과 원본·검증 이력은 유지하고, 개발 확인은 Replit의 필요한 정적 검사로 한정한다.
