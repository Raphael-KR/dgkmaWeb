# 6.4.0 릴리스

밴드에서 시험 이전한 게시글·댓글의 첨부와 영상 재생, 회원 사진첩 및 프로필 소속 표시를 추가했다. 기존 회원 접근과 일반 첨부 경로를 보존하는 기능 추가로 MINOR를 올렸다. [PR #47](https://github.com/Raphael-KR/dgkmaWeb/pull/47)의 main 커밋 `44f8b453aa93c54fa763e6a8f934de2a16ee864d`가 배포 후보이며 `v6.4.0` 태그 대상이다. 후보 tree는 `f60e92cfd6ec8cf47f5b43098bdf4f3e08482555`다.

## 후보 검사

2026-11-26 Replit 개발 환경의 Node 20.20.0에서 ESLint와 Prettier 체크 대상 55개, 앱·테스트 타입 및 모듈 경계, Node·Python 구문 검사, 배포 빌드를 통과했다. 게시판·회원 권한·프로필·경조사·공유 계약을 포함한 변경 범위의 기존 기능 검사 107개가 통과했다. 역사관 공개 자료 검사와 회원 사진첩 115개·사진 항목 3,190개의 참조 검사를 마쳤다. GitHub main을 동기화할 때 Replit에서 검사한 작업 사본의 소스 파일 744개를 후보 tree와 대조했다.

기존 비로그인 접근 검사에 밴드 영상·사진첩 경로를 추가했다. 개발에서 실행한 후보 영상 경로는 실제 운영 비공개 저장 파일의 목록과 헤더 요청에 200, 앞·뒤 바이트 구간 요청에 206, 범위를 벗어난 요청에 416을 반환했다. 반환한 두 구간은 보존한 원본 바이트와 일치했다. 일반 댓글의 단일 첨부와 다음카페 출처 표시를 유지했다. 6.3.0 회원 전환용 임시 미들웨어를 제거했고, 운영의 두 트리거가 활성 상태임을 확인했다.

## 운영 데이터와 시험 작업 사본

배포 전 로컬에 보존한 12,112개 파일의 SHA-256을 Replit 작업 사본과 다시 대조했다. 승인된 Replit 시험 작업 폴더 두 개를 삭제했고 로컬 보존 사본, 운영 DB 자료, 비공개 저장소를 유지했다. [게시판·사진첩 운영 시험](band-production-promotion-trial-2026-11-26.md)

삭제 후 `neondb`의 읽기 전용 연결에서 게시글 6,838건과 댓글·답글 5,365건을 확인했다. 게시글은 다음카페 80건과 밴드 6,758건이다. 회원 기본명부 3,461명, 승인 계정 4명, 가입 심사 1건과 빈 회비 구조를 확인했다. 운영 데이터 재이관과 비공개 저장 객체 변경은 없이 배포했다.
