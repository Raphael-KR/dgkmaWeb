## 적용·검사 상태

기준 문서를 먼저 반영한 뒤 로컬·Replit 개발 사본에 적용했다. 이번 작업은 기존 파일 23개 수정과 공통 조회 오류 UI·이력 문서 2개 추가다. 기존의 다른 미커밋 변경은 보존했다.

- 소스 기준: 로컬 `main`은 `d7184ca5238e0cdc3e91515ac0616e3b33332f41`, Replit 개발 `main`은 `587202723e943cb2cc9c3d3e1daf022770f33342`다. 이번 변경은 작업 사본에만 있으며 커밋·push·PR·병합하지 않았다.
- 검사 환경·일자: Replit 개발 워크스페이스, 2026-11-10 KST.
- `npm run check`: 앱 타입과 의존 경계·런타임 순환 참조의 정적 검사 통과, 앱 파일 251개.
- 변경 TypeScript/TSX 20개 파일의 ESLint: 통과.
- 기존 로그·라우트·문서 소스 계약 검사: 13개 통과. 파일 읽기와 구문 분석만 수행하며 앱·DB·외부 API를 실행하지 않았다.
- 보존 비교 8개 통과: 첨부 처리의 로그 외 실행 구문, 서버 로그아웃·세션 정리, 클라이언트 로그인·인증 확인, 기존 안전 로그 함수, 경조사 초안·생성·게시 순서가 유지됨을 소스로 대조했다.
- 문서의 상대 링크·앵커와 `git diff --check`를 확인했다. 변경 파일은 내용 해시로 Replit 개발 사본과 대조했다.

권한의 실제 실행 결과를 확인한 것은 아니다. DB 접속·변경, 실제 외부 API 호출, 서버 재시작, 빌드·배포, 브라우저·실계정 QA는 수행하지 않았다. 운영 적용 상태와 마지막 확인 시각은 [Replit 기준](../../replit.md#현재-적용-상태)을 유지한다.
