- 원래 파일명은 App Storage 객체 메타데이터에 인코딩해 저장하고 다운로드 응답에 사용한다. 일반 파일은 octet-stream·attachment·nosniff·private/no-store로 반환한다. 업로드 토큰은 발급 회원·파일명·형식·크기·만료를 묶고 요청 로그에서는 토큰 경로를 가린다.

## 일반 파일 10MB·5개 제한

- 목표: 사용자 결정에 따라 일반 파일을 파일당 10MB·게시글당 5개로 제한한다.
- 범위: 공통 제한·클라이언트 업로드·서버 URL/토큰/수신·게시글 저장 검증과 안내. 기존 이미지 5MB·전체 합계 40개를 유지한다.
- 완료 조건: 기존 본문과 새 업로드를 합산하고 선택·붙여넣기·드롭·직접 API 저장에 같은 기준을 적용한다. 기존 한도 초과 자료는 자동 삭제하지 않는다.
