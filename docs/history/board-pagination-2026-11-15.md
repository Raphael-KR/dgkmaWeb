# 게시판 이어보기·이관 실행 기준 정리 — 2026-11-15

공개 게시판과 권한에 따른 가린 글 목록에 limit/offset 페이지 처리를 추가했다. 기존 배열 응답과 회원·가림 권한을 유지한다. 50건 단위 더 보기·추가 조회 실패 시 재시도를 제공한다. 분류·가림 보기별 캐시를 구분한다. 공개 글은 게시일(없으면 생성일) DESC, id DESC; 가린 글은 수정일 DESC, id DESC다. 검색의 같은 날짜 정렬에도 id DESC를 추가했다. offset 조회는 스냅샷이 아니므로 조회 중 신규 작성·삭제가 있으면 새로 불러와 목록을 갱신한다.

2026-11-15 Replit에서 변경 코드 서식·lint·앱 타입·의존 경계 검사를 통과했다. 브라우저·DB 페이지 실행 시험은 하지 않았다.

사용자 결정: 다음카페는 증분 병합 없이 전체 자료를 일회성 이관한다. 실제 이관 직전에 대상 환경의 posts 전체 행과 종속 댓글을 리셋한다. 지금 리셋은 실행하지 않았다. 회원·명부·회비·카테고리·원본 백업은 제외한다. 사진첩도 일회성 반영이며 파일 물리 삭제 범위는 DB 리셋과 구분한다. 적용 도구·사진첩 병합 도구는 설명만 했으며 이번에는 수정하지 않았다.

선택된 HWPX는 내부 내용 대조를 하지 않고 첨부한다. 외부 PCX 참조 누락은 원본 특성이며 보류하지 않는다. 기존 업로드 형식·용량·압축 파일 보안 검사는 유지한다. 원문 재수집·실제 이관·DB/Storage 변경·서버 재시작·배포·실계정 QA·Git 게시는 하지 않았다.

밴드도 백업만 증분 수집하고 이관은 확정한 전체 백업본의 일회성 반영으로 결정했다. posts 리셋을 플랫폼별 자동 반복으로 구현하지 않으며 선행 이관 자료가 지워지지 않도록 실제 실행 순서에서 구분한다.

환경 기준도 확정했다. 다음카페·밴드 모두 테스트 이관은 개발 DB·개발 파일 저장소, 운영 개시 직전 최종 이관은 운영 DB·운영 파일 저장소를 사용한다. 이 결정에 따른 실제 리셋·이관은 아직 실행하지 않았다.
