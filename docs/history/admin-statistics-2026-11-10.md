## 반영 범위

- 기준 main: `6ccdbfdd145ad9194dd58b1b19df28063c4b72a0`. 기존 미커밋 계획서의 기능 목록·우선순위와 회비 개발 보류 결정을 보존하고, 제품·운영·구조 기준을 먼저 갱신했다.
- 로컬과 Replit `/home/runner/workspace`에 관리자 통계 API·기간 입력·현황 카드·분류별/일별 표를 반영했다. 공통 관리자 guard, 요청·오류 UI, 카드·입력·회원 화면 CSS를 재사용했다.
- 한 SELECT의 동일 snapshot으로 기존 회원·가입 대기·명부 연결·발행 글을 집계한다. 현재 회원 수와 명부 행 수를 구분하고, 날짜 없는 발행 글의 기간 집계 제외 건수를 안내한다. 개인정보 원문을 통계 응답에 담지 않는다.
- 통계의 현재 현황과 게시글 기간 필터를 구분한다. 탭 진입·기간 변경·수동 갱신 때 조회하며 가입 심사·명부 동기화·게시글 변경 후 캐시를 무효화한다. 통계 탭 진입으로 Sheets 연결 확인을 시작하지 않는다.
- DB 구조·회비 판정·명부 원본 정책은 변경하지 않았다. DB 직접 조회·쓰기, Sheets 조회/동기화, 빌드, 서버 재시작, 운영 배포와 실계정 QA는 실행하지 않았다. Git commit·push·PR·merge도 이번 범위에 없다.

## 후속 릴리스 승인과 범위

초기 개발 완료 후 사용자가 관리자 기초 통계와 기타 미커밋분 모두의 커밋·push·PR 생성·main 병합·Replit 릴리스를 요청했다. 위 초기 개발의 제외 범위와 구분해 다음 범위로 진행한다.

- 목표: 관리자 기초 통계와 확정 계획을 GitHub main과 Replit 운영에 반영한다.
- 범위: 로컬·Replit main `6ccdbfdd145ad9194dd58b1b19df28063c4b72a0` 위의 미커밋 파일 17개. 관리 파일 525개가 일치하며 기타 미커밋분은 기능 목록·개발 우선순위와 회비 개발 보류를 포함한 문서 변경이다.
- 완료 조건: 후보 commit·push·PR·main 병합, 개발 main 반영, 새 Republish 성공과 비로그인 운영 확인을 구분해 기록한다. 이번 임시 작업 브랜치는 병합 후 정리한다.
- 제외: DB 구조·데이터·Secrets·회비 판정 변경, 실계정 QA, 실제 게시·명부 동기화·외부 수집·유료 API 호출, 개발 서버 별도 재시작과 자동 롤백.
- 검증: 통계 코드 12개의 해시가 기존 검사와 일치하므로 타입·lint 결과를 재사용한다. 릴리스 빌드·변경 문서 정합성 및 배포 후 비로그인 공개 HTTP·canonical·회원/통계 API 인증 차단·후보 자산 해시를 확인한다. 실제 회원·관리자 통계 사용 흐름과 DB 집계 실행은 확인 범위에 포함하지 않는다.
