## 유지하는 검사

- 타입·ESLint·변경 파일 서식·브라우저 의존 경계: 컴파일·Hooks·기본 코드 오류와 서버 코드의 브라우저 유입을 확인한다. 동일 소스의 통과를 반복하지 않는다.
- 현재 입력/정규화·권한·DTO·OAuth·회비·개인정보·경조사 URL·공개 수집 제한: 실제 결과와 실패 경계를 확인한다. 같은 함수의 다른 입력·위험을 단순 중복으로 취급하지 않는다.
- 실제 DB 8개 파일·11개 사례: 등록·승인·탈퇴·동기화의 경쟁과 보존은 타입 검사로 대체할 수 없다. 기존 opt-in·대상 확인을 유지하며 이번에는 실행하지 않는다.
- 해시 자산 교체 후 오래된 탭 복구: 새 배포로 기존 탭이 깨지는 실제 회귀를 보호하므로 별도 요청용으로 유지한다. 두 빌드와 CDP 보조의 실제 소비자를 확인한다.
- 역사관 자료의 날짜·ID·파일 참조와 DB 운영 도구의 대상/보존 검사: 자료·운영 작업의 정확성을 직접 보호한다. 일상 검사에 추가하지 않는다.

과거 문서와 ignored 검증 로그는 수행 증거로 보존하며 재실행 목록으로 사용하지 않는다. 현재 제품 정책·저장 데이터·권한 판정은 바꾸지 않는다.
