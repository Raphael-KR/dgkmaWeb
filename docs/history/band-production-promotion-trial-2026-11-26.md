# 게시판·사진첩 운영 이전 시험

2026년 11월 26일 02:23 KST에 11월 25일 마감 개발본을 Replit 운영 DB와 비공개 저장소로 시험 이전했다. 운영 게시글과 종속 댓글은 한 트랜잭션에서 교체했다. 사진첩 카탈로그는 파일을 대조한 뒤 발행했다. 마지막 밴드 게시일과 홈페이지의 정식 전환은 별도 결정이다.

## 반영과 검산

| 대상 | 운영 시험 전 | 운영 시험 후 |
|---|---:|---:|
| 다음카페 글 | 80 | 80 |
| 밴드 글 | 0 | 6,758 |
| 밴드 댓글·답글 | 0 | 5,365 |
| 사진첩 | 52 | 115 |
| 사진 항목 | 406 | 3,190 |

개발 `heliumdb`의 게시글·댓글과 사진첩을 내보내고 문서·파일 참조와 해시를 검증했다. 운영 `neondb`에서 댓글 상위 연결과 원천 ID, 작성 당시 소속을 저장하는 컬럼 5개와 제약을 적용했다. 읽기 전용 metadata catalog에서 테이블 14개·컬럼 134개, FK 10개·CHECK 20개·인덱스 30개를 확인했다.

운영 저장 객체 12,391개의 바이트 해시와 파일 형식, 첨부 다운로드 이름, 밴드 객체의 비공개 범위를 대조했다. 재생 목록 131개는 영상 참조 159건을 연결한다. 운영 DB의 새 연결에서 글과 댓글의 ID·본문·원작성 메타데이터, 답글 40건의 상위 ID를 묶음과 대조했다. 운영 사진첩 카탈로그의 해시도 일치했다.

회원 명부 3,461명, 승인 계정 4명 중 관리자 1명, 가입 심사 1건, 로그인 세션 4건을 확인했다. 회원·명부·가입 심사·별칭·게시판 분류의 전후 지문이 일치했다. 운영 회비 입금과 배분은 각각 0건이다.

## 검사와 근거

- Replit에서 변경 코드의 ESLint, 서식, Node 구문, TypeScript와 브라우저·서버 의존 경계를 검사했다.
- 공개 홈은 HTTP 200이었다. 비로그인 요청 7건은 모두 401이었다. 글 목록·상세·댓글, 사진첩·사진, 밴드 첨부와 영상의 비공개 물리 경로를 확인했다.
- 운영 앱 버전은 6.3.0이다. 밴드 첨부 표시와 동영상 재생의 회원 화면 검증은 지원 코드 배포와 실계정 QA 범위다.
- 개발본 SHA-256은 `b6528069e17a7b5d259d161555a217047f2737d4a8278e20ec0df88e9295a040`, 운영 검증 영수증 SHA-256은 `8c6a29cadf0ff950c60144be77e65921479d708b1d221bda51c43c007a05019b`이다. 원본과 운영 ID 대응은 비공개 영수증에 보관한다.
