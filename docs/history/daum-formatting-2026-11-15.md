# 다음카페 본문 서식 변환 보완 — 2026-11-15

사용자가 /p/81에서 지적한 원문 dbpl:50의 해당 소제목은 span의 font-weight:bold로 표현되어 있었다. 기존 변환기는 strong/b 태그만 읽어 이를 놓쳤다. 백업 contentHtml에는 원래 스타일이 남아 있어 재수집 없이 변환기를 수정했다.

prepare-post-migration.py에서 현재 Tiptap이 지원하는 bold/italic/underline/strike에 대응하는 인라인 CSS를 해석한다. H1~H4·목록·인용·구분선·코드도 대응 노드로 변환하고 표 안에서 상속된 인라인 서식을 전달한다. 글꼴·크기·색상·정렬 확장은 추가하지 않는다. 제목 레벨을 글자 크기로 추정하지 않는다. 실행 가능한 HTML·임의 CSS를 문서에 저장하지 않는다.

로컬 후보 80건을 재생성해 실패 0건과 원문 텍스트 보존 대조를 확인했다. dbpl:50의 사용자가 지적한 소제목에 bold mark가 있음을 직접 대조했다. 전체 후보의 bold 텍스트 노드는 94개다. 학술 첫 문단 #학술 59건·지정 제외 2건·첨부 11개를 유지하고 tar의 posts.json도 최종 JSON과 대조했다. verification.json의 도구·출력 해시를 갱신했다.

Replit 개발 환경에는 개인정보 없는 도구 소스와 문서만 반영하고 변경 Python의 AST 구문 검사만 수행한다. 실제 원문이 없는 서식 종류의 변환 실행이나 모든 문서의 Tiptap 실행형 스키마 검증·브라우저 표시는 확인하지 않았다. 초기 재생성에서 잘못 전달된 marks 변수 오류를 수정한 뒤 전체 후보 생성을 다시 수행했다.

백업 원문·과거 테스트 payload·실제 /p/81의 DB 데이터는 변경하지 않았다. 실제 재이관·DB/Storage 작업·배포·실계정 QA는 수행하지 않았다. 화면의 기존 테스트 글은 이번 준비 자료 수정만으로 바뀌지 않는다.
