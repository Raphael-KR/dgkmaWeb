# 댓글·법적 안내 공통화와 현재 문서 축소

2026-11-10 승인 범위는 아래 4건이다. [계획서](../product/planning-proposal.md), [구조 기준](../architecture/project-structure.md), [Replit 운영 기준](../../replit.md)을 먼저 갱신한 뒤 로컬·Replit 개발 사본에 적용했다.

| 항목 | 변경과 보존 범위 |
|---|---|
| 댓글 검증 | shared/contracts의 스키마·타입을 영속성 호환 경로에서 재사용한다. 기존 export, 입력 제한·오류 문구, URL·세션 기반 식별자와 회원 권한을 유지한다. DB 구조 변경은 없다 |
| 법적 안내 | legal 내부 공통 틀에서 레이아웃·Card·뒤로가기를 공유한다. 각 페이지 SEO·제목·개정일·원문·스타일을 유지한다 |
| 대기시간 인수 | 모바일 측정·복구 도구의 호출자가 바꾸지 않는 시간 인수만 내부 상수로 좁힌다. 700ms·20초·12초와 실제 사용 중인 공통 CDP 제한시간 인수를 보존한다 |
| 현재 문서 | Replit 기준과 계획서에서 완료된 정리 목록·반복 검사 기록을 줄이고 기존 이력 색인으로 연결한다. 현재 Git·개발 사본·마지막 운영 상태, 남은 기능과 보존 정책은 유지한다 |

## 적용·확인 결과

- 문서 5개를 먼저 반영한 뒤 코드 6개를 적용했다. 변경마다 Replit 개발 사본의 파일 집합·내용을 대조하고 기존 사본을 보존했다. 이력 색인에 이번 기록을 연결했으며 기존 날짜별 기록은 수정하지 않았다.
- 로컬 main `d7184ca5238e0cdc3e91515ac0616e3b33332f41`, Replit main `587202723e943cb2cc9c3d3e1daf022770f33342`를 유지한다. 변경은 미커밋 상태이며 공통 화면과 이력 파일 추가로 관리 대상은 499개에서 501개가 됐다. Git 통합·운영 반영 결과가 아니다.
- 약관·개인정보 본문은 들여쓰기 외 내용을 대조했고 제목·개정일·SEO 경로를 보존했다. DB 테이블 정의, 댓글 API·공통 검증·호환 진입점, 공통 CDP 함수는 변경 전과 같다. 공통 화면의 기존 스타일·뒤로가기 분기는 소스로 확인했다.
- 2026-11-10 17:53 KST Replit 개발 환경에서 `npm run check`(타입·의존 경계·runtime cycle), 변경 코드 6개 ESLint, 파일 기반 문서 계약 6건과 `git diff --check`가 통과했다. 문서 82개·내부 링크 720개·앵커 258개의 파일 검사도 오류 0건이다. npm 실행의 `C.UTF-8` locale 경고는 있었으며 검사 종료 코드는 모두 0이다.
- 검사 코드는 수정하지 않았으며 같은 소스의 타입·lint를 반복하지 않았다. 문서 결과 갱신 뒤에는 링크·diff와 개발 사본 일치만 확인한다.
- DB 작업·앱/브라우저/모바일 실행·빌드·서버 재시작·배포·실계정 QA·커밋·push·PR·병합은 수행하지 않았다. UI·댓글 작성·실제 브라우저 대기 동작을 실행한 결과로 해석하지 않는다.
