# 커뮤니티 노란색 테마 개발 기록

- 목표: 회원 커뮤니티의 노란색 테마를 복원해 공개홈의 주황색과 구분한다.
- 범위: 공통 CSS의 테마별 색상, 회원 화면 테마 범위, 헤더·탐색 표시와 관련 기준 문서.
- 완료 조건: 공통 로고·이름·반응형 구조를 재사용하며 회원 헤더·메뉴에 노란색과 짙은 글자가 적용되고 공개 화면의 색은 유지된다.
- 제외: 경로·권한·데이터·로그인 흐름 변경, DB 작업, Git 게시, 운영 배포와 실계정 QA.
- 검증: Replit 개발 사본에 반영한 변경 파일의 lint·서식·CSS 정적 처리, 문서 링크와 `git diff --check`. 브라우저·실계정 실행 확인은 수행하지 않는다.

## 결정과 구현 범위

2026-11-11 사용자 요청을 [제품 정책](../product/planning-proposal.md#공개-홈회원-커뮤니티의-공통-표시-2026-11-09)과 [구조 문서](../architecture/project-structure.md#본문공통-표시)에 먼저 반영했다. 공통 표시 통합 이전 커밋 `4ce2925^`에서 커뮤니티의 노란 강조색 `#FEE500`을 확인했다. 기존 반응형 화면의 배치와 공통 로고는 유지한다.

`AppShell`의 기존 `showMemberChrome` 판정으로만 회원 테마 범위를 정한다. 로그인한 회원의 `/`와 회원 화면은 노란색, 비로그인 `/`와 로그인 여부에 관계없는 `/about`·하위 공개 화면은 주황색을 사용한다. 공개 화면에서도 제공하는 기존 하단 탐색·로그인 유도 동작은 유지한다.
