# 과거 설계·구현 계획

이 디렉터리는 당시 원문을 보관한다. 각 파일 상단에 상태·작성 시점(파일명)·현행 정본을 표시한다. 현재 실행 기준은 [제품·개발 계획](../product/planning-proposal.md), [Replit 운영](../../replit.md), [DB 기준](../reference/database-schema.md)이며, 결정의 이유는 [ADR](../decisions/README.md), 실제 수행 결과는 [이력 색인](../history/README.md)을 따른다.

원문의 명령·미완료 체크박스·특정 도구 사용 지시는 이력이다. 모든 계획이 구현됐다는 의미도, 남은 모든 항목을 실행하라는 의미도 아니다. 파일 경로는 기존 참조를 위해 유지한다.
