# 동문회 기업은행 송금

기장이나 분개만 요청하면 [동문회 일반회계 통장 기장](../dgkma-bank-ledger/SKILL.md)으로 바로 시작한다. 송금 요청은 지급 근거와 중복을 확인해 이체하고, 출금 확인 후 같은 기장 스킬까지 실행한다. 사용자가 이미 송금했으면 이체결과 확인부터 이어간다. 조회만 요청하면 조회 결과를 보고하고, 은행 메모 정정만 요청하면 아래 ‘이체와 은행 메모’ 4번을 따른다.

## 지급 근거와 중복 확인

1. 노션 [동문회 기본 정보](https://app.notion.com/p/30f2225d9c4d80829b4bcb02cf49c110)에서 일반회계 출금계좌와 지급처의 은행·계좌번호·예금주를 확인한다. 지부 계좌도 본회와 예금주명이 같을 수 있으므로 계좌번호로 구별한다. 지급처가 명시된 자료에서 확인되지 않으면 사용자에게 필요한 계좌 정보만 요청한다.
2. `read-kakao-room-from-lake`로 해당 회계연도 **회장단방과 임원방**에서 수취처·금액·안건을 함께 찾는다. 2026년 방 이름은 ‘제22대 동문회장단’, ‘22대 동국한의동문회 임원방’이다. 제안, 지급 결정, 이사회 보고, 실제 송금 알림을 구분한다. 은행 거래 메모는 **어디에, 무슨 명목으로 지급했는지** 알 수 있게 결정된 안건의 표현으로 작성한다. 예를 들어 부산지부에 초기 1회 활동비를 지급한 건은 `부산지부 초기활동지원금`이다. 지급 목적이 모호하면 가능한 근거를 먼저 살핀 뒤 남은 쟁점만 묻는다.
3. `ego-browser`로 IBK 기업인터넷뱅킹의 해당 일반회계 계좌를 연다. 기존 지급 여부는 사용자가 지정한 기간 전체에서 확인한다. 기간 지정이 없으면 지급 결정일(불분명하면 해당 회계연도 시작일)부터 현재까지 기존 장부·은행 원장과 대조한다. 은행 거래내역 전체 페이지에서 수취계좌·금액·지급 명목을 확인한다. 같은 금액의 다른 수취처나 같은 수취처의 다른 지급 건은 구별한다.
4. 동일 건의 출금이 확인되면 기존 거래를 기준으로 메모·기장의 요청 범위를 처리한다. 대응하는 출금이 없으면 이체결과와 예약·결재 대기 내역에서 같은 지급 지시가 남아 있는지도 확인한다. 처리가 진행 중이거나 조회 범위가 불완전하면 확인될 때까지 새 이체를 보류한다.

## 이체와 은행 메모

1. 지급처·금액이 승인된 건만 즉시이체에 입력한다. 기존 로그인 화면을 이어 쓰고, 로그인이 필요하면 기업 금융인증서로 진행한다. **‘내 통장에 표시할 내용’은 빈칸**으로 두어 은행 기본값인 수취계좌 이름을 남긴다. **입금계좌정보의 선택 입력란 ‘예금주’도 빈칸**으로 둔다. [기업은행 이체 입력 기준](https://app.notion.com/p/4212225d9c4d81fc8e57e64d0ed61bc9)
2. 이체 확인 화면에서 실제 출금계좌·입금은행·수취계좌·금액과 은행이 조회한 예금주를 지급 근거에 대조한다. 표시명이 줄어든 경우 계좌번호도 함께 확인한다. 불일치하면 실행을 멈춘다. 비밀번호·OTP·전자서명이 필요한 단계는 같은 은행 화면을 사용자에게 넘기고, 사용자가 마치면 같은 화면에서 이어간다. 비밀번호나 인증번호를 채팅으로 받지 않는다.
3. 완료 화면 또는 이체결과에서 정상 처리 건수, 수취계좌, 금액, 수수료를 확인하고 실제 출금의 일시(초)와 거래 후 잔액을 찾는다. 사용자가 직접 송금을 끝냈거나 서명 후 오류·시간 초과가 발생하면 **결과조회와 실제 출금을 먼저 대조**한다. 결과가 불명확한 동안 재송금하지 않는다.
4. **송금 후**, 완료 화면의 ‘메모등록’ 또는 거래내역조회의 ‘메모 등록/변경’에서 확인된 출금 **한 건**에 수취처와 지급 명목을 기록한다. 거래내역을 새로 조회해 같은 행의 저장 문구와 띄어쓰기를 확인한다. 이미 기장한 건에서 메모만 정정할 때는 은행 조회 결과를 기준으로 은행 원장 ‘메모’와 연도별 장부 ‘메모’의 해당 셀만 맞춘다. 2026년 기업은행 원장은 I열, 연도별 장부는 H열이다. 행번호와 열은 실제 헤더·거래로 다시 확인한다. 메모 정정만 요청한 경우에는 지정한 곳의 메모를 재조회하고 종료한다.

## 이체 후 기장

- 실제 출금을 확인하고 은행 메모를 저장한 뒤 [동문회 일반회계 통장 기장](../dgkma-bank-ledger/SKILL.md)을 같은 작업에서 실행한다. 출금계좌, 수취처와 용도, 실제 출금의 일시·금액·잔액, 메모 저장 결과를 넘긴다. 같은 계좌에서 여러 건을 이체했으면 모두 확인해 한 번에 기장한다.
- 기장 스킬은 이체 후의 은행 조회시각을 기준으로 해당 계좌의 마지막 검산 거래부터 전체 입출금을 증분한다. 이미 은행 메모까지 반영한 전체 조회 결과가 있으면 함께 넘긴다.
- 메모 저장이 실패해도 실제 출금은 기장하고 미확인 메모를 표시한다. 기장이 일부만 반영됐으면 두 장부를 다시 대조하는 단계부터 재개한다. 송금 성공 여부가 불분명하면 ‘이체와 은행 메모’ 3번으로 돌아간다.
- 이체 결과와 수수료, 은행 메모 상태, 기장 스킬에서 확인한 반영 행·최종 잔액·누락·중복·체크썸과 피벗 검산 결과를 함께 보고한다. 계좌번호 전체나 인증 자료는 프로젝트 파일과 보고서에 남기지 않는다.
